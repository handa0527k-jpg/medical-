## テーマ1　遺伝子とは何か
@slide 42
> そもそも遺伝子とは何なのか。スライド42で定義を確認します。
>[m1] 遺伝情報を担うDNAは、生物の構造や機能を決める設計図です。
>[m2] 遺伝情報は、どんなタンパク質を、どの細胞が、どんな環境で、どれだけ作るか。さらに、作られたタンパク質の行き先や分解の速さまで指令しています。
>[m3] そして赤い文字。遺伝子とは、DNAの中で、タンパク質のアミノ酸配列、あるいは翻訳されないRNAの塩基配列を決める情報を持った領域です。

>[m5] どちらの鎖を鋳型にするかは遺伝子ごとに違い、転写の向きを決めるのは、それぞれの遺伝子のプロモーターです。

## テーマ3　転写・スプライシング・翻訳
@bb
@cam C
@in C 0 340
+s {f1} [y:転写]：DNA → 前駆体RNA（イントロンも）
+s {f2} [y:スプライシング]：イントロンを除く
+s {f3} [y:翻訳]：コドン → アミノ酸
> 流れを書きます。転写で、イントロンも含んだRNAができる。スプライシングで、イントロンを取り除く。そして翻訳。
+sb {f4} 文字：A G C T → U C G A（TがUに）
> 転写のとき、DNAのTは、RNAではUになります。第2講でやったウラシルですね。

@anim expr
>[s0] では、実際の流れを分子のレベルで見てみましょう。DNAの上の遺伝子です。
>[s1] RNAポリメラーゼが、プロモーターに結合します。ここが読み始めの場所。
>[s2] ポリメラーゼがDNAを読み進めながら、RNAを合成していきます。この時点では、イントロンの部分も写し取られています。
>[s3] 次にスプライシング。イントロンが輪のように外れて……エクソンだけがつながった、成熟したmRNAになります。
>[s4] mRNAは、核から細胞質へ出ていきます。
>[s5] ここから翻訳です。開始コドンAUGから、3塩基ずつ読まれていきます。AUGはメチオニン、GCUはアラニン、GUUはバリン。
>[s6] そして、終止コドンのUAG。ここにはアミノ酸がありません。合成はここで終わります。
>[s6!] メチオニン、アラニン、バリン。3つのアミノ酸がつながりました。

@bb
@cam C
@in C 20 600
+sk {mrna} mrna AUG GCU GUU UAG
> 黒板にも、今のmRNAを書いておきます。AUG、GCU、GUU、UAG。
> 下にアミノ酸。メット、アラ、バル。そして終止。
!o mrna
>! 開始はAUG、終わりは終止コドン。コドンは3つずつ。これが翻訳のルールです。

@slide 54
> スライド54で、ルールを確認しましょう。
>[m1] 1、特定の開始コドンから、タンパク質の合成が始まる。
>[m2] 2、途中のコドンの並びで、アミノ酸の配列が決まる。
>[m3] 3、終止コドンで、合成が終わる。
>[m4] 開始コドンより前と、終止コドンより後ろは、タンパク質をコードしない部分です。

@quiz g54b typical ref=mrna
> では典型問題です。このmRNAが翻訳されると、どんなペプチドができるでしょう。5ダッシュ側の端から読み始めないのがコツです。
@think 20
@explain
>[q] 配列の問題は、まず開始コドンAUGを探します。
>[A] 正解はA。AUGでメチオニン、GCUでアラニン、GUUでバリン、UAGで終止。
>[B] Bは、5ダッシュの端のAUAから、3文字ずつ読んでしまった答えです。翻訳はAUGから始まります。
>[C] Cは、終止コドンの後ろまで読んでしまっています。
>[D] Dは、3ダッシュ側から読んだ答え。向きが逆です。
>[E] Eは、終止コドンを取り違えています。
> AUGを探す、3つずつ区切る、終止コドンで止める。この3ステップです。

@quiz g41a check ref=f2
> もう一つ確認です。前駆体RNAからイントロンを除いて、エクソンどうしをつなぐ過程は何でしょう。
@think 8
@explain
>[C] 正解はC、スプライシングです。
>[B] 転写は、DNAからRNAを作る過程。
>[D] 翻訳は、RNAからタンパク質を作る過程でした。

@slide 78
> 転写がどこで、どれくらい起こるかは、プロモーター以外の配列でも調節されています。スライド78。
>[m1] 遺伝子から数百から数千塩基対も離れた場所の、エンハンサーやサイレンサーが、細胞ごとの調節的な発現に関わります。
>[m3] 近い位置の要素とプロモーターは、基礎的な発現を担います。

> タンパク質にならないRNAの遺伝子を、非コードRNA遺伝子、ncRNAと呼びます。スライド46。
>[m1] 産物がRNAそのものである遺伝子で、タンパク質コード遺伝子とほぼ同じ、2万から2万5千くらいあると推定されています。
>[m2] tRNAやrRNA、snoRNAなど、細胞の基本の仕組みを支えるものがあります。
>[m3] そして、miRNA。約22塩基の短いRNAで、
>[m4] 標的のmRNAに結合して翻訳を抑えます。
>[m6] 15番染色体のsnoRNA遺伝子群が欠けるとプラダー・ウィリー症候群、
>[m7] 13番のmiRNA遺伝子群が欠けるとフェインゴールド症候群です。

@keys 今日の重要ポイント
- 遺伝子＝**タンパク質のアミノ酸配列**または**翻訳されないRNAの塩基配列**を決めるDNA領域（ヒトは約31億塩基対に約2.5万遺伝子） @l1,l2,l3,l4
- 構造：**プロモーター → 5'UTR → 開始コドン(ATG) → エクソン／イントロン → 終止コドン → 3'UTR → ポリアデニル化シグナル** @gene
- 転写（T→U）→ **スプライシング**（イントロン除去）→ 翻訳。転写の向きは**プロモーター**が決める @f1,f2,f3,r3
- 翻訳は**AUG（Met）**から3塩基ずつ、**終止コドン（UAA・UAG・UGA）**で終了 @mrna,r1,r1b
- アミノ酸指定配列はゲノムの**約1.3%**。**miRNA**（約22塩基・翻訳抑制）などncRNA遺伝子の欠失でも疾患（プラダー・ウィリー、フェインゴールド） @g1,n1,n2,n3
> 重要ポイントを5つにまとめました。次の第5講では、この設計図の文字が変わったら何が起こるのか。変異と個人差の話です。
