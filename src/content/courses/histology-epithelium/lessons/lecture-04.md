## 導入
@title
> 第4講、「接着装置と基底面の構造」です。
> 密着帯の下には、ブロック同士をつなぐ金具が並んでいます。それから、隣どうしの小窓。最後に、壁を土台に留める金具と、土台側のひだ。上皮細胞の基底面には、どのような構造が見られるか、までを見ていきます。(間)

@goals この授業で押さえてほしい3つ
- **接着帯**：帯状・**15〜20 nm**・**カドヘリン**＋**アクチン**。**デスモゾーム**：斑状・**約30 nm**・デスモグレイン／デスモコリン＋**ケラチン**
- **ギャップ結合**：**2〜3 nm**・**コネクシン6量体＝コネクソン**・**1 kDa以下**が通る・心筋や神経にも
- 基底面：**ヘミデスモゾーム**（**インテグリン**→ラミニン・IV型コラーゲン）、**基底陥入**（Na⁺-K⁺ ATPase＋ミトコンドリア、光顕で**基底線条**）
> 押さえてほしいのは3つです。
>[1] まず、接着帯とデスモゾームの違い。
>[2] 次に、ギャップ結合。
>[3] そして、基底面のヘミデスモゾームと基底陥入です。

## テーマ1　接着帯
@roadmap 1
> まずは、接着帯です。

@board 接着帯（アドヘレンス結合）
+ **密着帯の下**、細胞全周に **帯（ベルト）状**
+ 隣り合う細胞膜の間隔：**15〜20 nm**
+! 細胞接着分子 **カドヘリン** 同士がCa依存性に結合（上皮：E-カドヘリン、神経：N-カドヘリン）
+! 細胞質側：裏打ち蛋白質を介して **アクチン線維** と結合
+ 意味：細胞同士の **機械的結合**、シグナルも伝達
> 結論から。接着帯は、密着帯のすぐ下で、細胞の全周をベルトのように回っています。膜の間隔は15から20ナノメートル。細胞接着分子のカドヘリン同士が、カルシウムに依存して結合します。上皮ではEカドヘリン、神経ではNカドヘリン。細胞の内側では、裏打ち蛋白質を介して、アクチン線維とつながります。意味は、細胞同士を機械的につなぐこと。シグナルも伝えます。

## テーマ2　デスモゾーム
@roadmap 2
> 次は、デスモゾームです。

@board 接着斑（デスモゾーム）
+ 接着帯の下に不規則に分布、**楕円形の斑（スポット）状**
+ 隣り合う細胞膜の間隔：**約30 nm**
+ カドヘリンファミリーの **デスモグレイン・デスモコリン** 同士がCa依存性に結合
+ 裏打ち蛋白質（デスモプラキン・プラコグロビン）が **プラーク** をつくる
+! 中間径フィラメントの **ケラチン線維** がヘアピン状に結合
+ 意味：細胞間の **機械的結合の補強**、シグナル伝達にも関与
> 結論から。デスモゾームは、接着帯の下に、楕円形のスポットとして点々とあります。膜の間隔は約30ナノメートル。カドヘリンの仲間、デスモグレインとデスモコリンが、カルシウムに依存して結合します。内側には、デスモプラキンなどの裏打ち蛋白質が厚い板、プラークをつくり、そこに中間径フィラメントのケラチン線維が、ヘアピンのように掛かります。意味は、細胞どうしの機械的な結合を補強すること。
!5

@compare 接着帯とデスモゾーム
| | 接着帯 | デスモゾーム |
| 形 | 全周に **帯状** | **斑（スポット）状** |
| 膜の間隔 | 15〜20 nm | 約30 nm |
| 接着分子 | カドヘリン | デスモグレイン・デスモコリン |
| つながる線維 | **アクチン線維** | **ケラチン線維** |
> 並べてみます。
>[1] 形は、接着帯がベルト、デスモゾームがスポット。
>[2] 膜の間隔は、15から20と、約30ナノメートル。
>[3] 接着分子は、カドヘリンと、その仲間のデスモグレイン、デスモコリン。
>[4] つながる線維は、アクチンとケラチンです。

@point 国境のたとえ :: 接着帯は壁を一周する **ベルト状の金具**（鉄骨＝アクチンに留める）、デスモゾームは要所を留める **鋲**（ワイヤー＝ケラチンを掛ける）。
> たとえで言うと、接着帯は、壁を一周するベルト状の金具で、内側の鉄骨、アクチンに留めてある。デスモゾームは、要所を留める鋲で、ワイヤー、ケラチンが掛かっています。

## テーマ3　ギャップ結合
@roadmap 3
> 三つ目のテーマ。ギャップ結合です。

@board ギャップ結合
+ 不規則に分布する **斑状** の装置。膜の間隔：**2〜3 nm**
+! **コネクシン** の **6量体＝コネクソン** が、直径 **1.5〜2.0 nm** の開閉可能なチャネルをつくる
+! イオン、アミノ酸、cAMPなど **分子量1 kDa以下** が通過
+ 上皮のほか **心筋・平滑筋・神経・骨細胞** にも
+ 意味：電気的興奮やシグナル因子、栄養の **細胞間直接伝達**
> 結論から。ギャップ結合は、点々とあるスポット状の装置で、膜の間隔は2から3ナノメートル。膜蛋白質のコネクシンが6つ集まったコネクソンが、向かい合ってトンネルをつくります。直径は1.5から2ナノメートルで、開け閉めができる。通れるのは、イオン、アミノ酸、サイクリックAMPなど、分子量1キロダルトン以下の小さな分子です。上皮のほか、心筋、平滑筋、神経、骨の細胞にもあります。意味は、電気的な興奮や、シグナル、栄養を、細胞から細胞へ直接伝えることです。

## テーマ4　ヘミデスモゾームと基底陥入
@roadmap 4
> 最後のテーマ。上皮細胞の基底面です。

@board ヘミデスモゾーム
+ **基底面** に存在する斑状構造。細胞膜と細胞間質（細胞外マトリックス）を接着
+! 接着分子 **インテグリン** が基底膜の **ラミニン**・**IV型コラーゲン** と結合
+ 細胞質側：裏打ち蛋白質を介して **ケラチン線維**
+ 意味：**上皮と基底膜間** の機械的結合の補強、シグナルも伝達
> 結論から。ヘミデスモゾームは、基底面にあるスポット状の構造で、細胞と、その下の細胞外マトリックスを接着します。接着分子はインテグリン。基底膜のラミニンや4型コラーゲンと結合します。内側では、ケラチン線維とつながる。意味は、上皮と基底膜の機械的な結合を補強することです。
!2

@pitfall ここで間違えやすい :: デスモゾームは **細胞と細胞**（カドヘリンファミリー）、ヘミデスモゾームは **細胞と基底膜**（インテグリン）。線維はどちらも **ケラチン**。
> ここ、間違えやすいところです。デスモゾームは細胞と細胞をつなぎ、接着分子はカドヘリンの仲間。ヘミデスモゾームは細胞と基底膜をつなぎ、接着分子はインテグリン。名前は似ていても、相手と分子が違います。ただ、内側のケラチン線維は共通です。

@example インテグリンの種類（補足） :: 講義資料の範囲外の補足：ヘミデスモゾームのインテグリンはα6β4で、基底膜のラミニン（ラミニン-332）と結合すると説明されることが多い。
> 補足です。資料の外の話ですが、ヘミデスモゾームのインテグリンは、アルファ6ベータ4という種類で、主にラミニンと結合すると説明されることが多いです。

@board 基底陥入（基底線条）
+ 場所：**唾液腺の導管**、**腎臓の尿細管** など **イオンを輸送する上皮** の基底面
+ 電顕：基底側の細胞膜の **深いヒダ**（膜の陥入＝細胞質の突起）
+! 膜に輸送体（例：**Na⁺-K⁺ ATPase**）→ **細胞膜の表面積を拡大**
+ 突起の間に **多数のミトコンドリア** → 輸送体にエネルギーを供給
+ 光顕では **基底線条**
> 結論から。基底陥入は、唾液腺の導管や腎臓の尿細管など、イオンを運ぶ上皮の基底面にあります。電顕では、基底側の細胞膜が深くひだになって見える。この膜には、ナトリウムカリウムATPアーゼのような輸送体があって、ひだで表面積を広げているんです。そして、ひだとひだの間には、たくさんのミトコンドリアが並び、ポンプにエネルギーを送っている。光顕では、縦じまに見えるので、基底線条と呼びます。
!3

@point 国境のたとえ :: 土台側の面を深く折りたたんで **ポンプ（輸送体）** を並べる場所を増やし、すぐ横に **発電所（ミトコンドリア）** を置いた部屋。
> たとえで言うと、土台側の壁を深く折りたたんで、ポンプを並べる場所を増やし、そのすぐ横に発電所を置いた部屋です。
