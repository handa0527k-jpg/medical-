## 導入
@title
> 第6講、「魚類から爬虫類へ」です。
> 脊索動物の二重の筒に、頭、顎、鰭、そして四肢と、部品が足されていきます。そのたびに、心臓の部屋の数と、腎臓の世代が変わっていく。今日の見どころはそこです。(間)

@goals この授業で押さえてほしい3つ
- **無顎類**（円口類）：顎なし、胸鰭・腹鰭なし、**二半規管**、前腎＋中腎
- **有顎類（魚類）**：**一心房一心室**、**三半規管**、中腎、卵生。**肉鰭類**（肺魚・シーラカンス）から両生類へ
- 心臓：両生類 **二心房一心室** → 爬虫類 **二心房不完全二心室**。腎臓：両生類 幼生 **前腎**・成体 **中腎** → 爬虫類 **後腎**
> 押さえてほしいのは3つです。
>[1] まず、最初の魚、無顎類。
>[2] 次に、顎をもった魚類。
>[3] そして、両生類と爬虫類で、心臓と腎臓がどう変わるかです。

## テーマ1　無顎類
@roadmap 1
> まずは、最初の魚類、無顎類です。

@board 無顎類（顎がない魚）
+ 現存：**円口類**（ヤツメウナギ、メクラウナギ）
+ からだ：二重の筒 ＋ **頭**。顎がなく、**咽頭が丸く開く**
+ **胸鰭・腹鰭がない**（成体で背鰭）
+! 内耳は **二半規管**（2次元で生活！）
+ 成体で目が出現。**眼は中枢神経系**　泌尿器系：**前腎＋中腎**
> 結論から。最初の魚類は、顎のない無顎類。今いるのは、ヤツメウナギやメクラウナギなどの円口類です。からだは、二重の筒に頭が足された形。顎がなく、咽頭が丸く開いています。胸びれと腹びれがありません。そして内耳は、二半規管。2次元で生活しているからです。成体になると目が出てきますが、眼は中枢神経系の一部です。泌尿器系は、前腎と中腎です。

## テーマ2　有顎類（魚類）
@roadmap 2
> 次は、顎をもった魚、有顎類です。

@board 有顎類の仲間
+ **軟骨魚類**：板鰭類（サメ、エイ）
+ **硬骨魚類**：**条鰭類**（タイ、ニシン）／**腕鰭類**（ポリプテルス）／**肉鰭類**（**肺魚・シーラカンス**）
> まず仲間分けです。軟骨魚類は、サメやエイの板鰭類。硬骨魚類は三つ。タイやニシンなど一般的な魚の条鰭類、ポリプテルスの腕鰭類、そして肺魚やシーラカンスの肉鰭類です。

@board 有顎類のからだ
+ からだ：二重の筒 ＋ 頭 ＋ **顎** ＋ **鰭**
+! 心臓：**一心房一心室**
+ 胸鰭・腹鰭（のちに **四肢へ進化**）。内耳：**三半規管**（3次元へ）
+ 泌尿器系：**中腎**　生殖器系：**卵生**
> からだは、二重の筒に、頭、顎、鰭。心臓は一心房一心室。胸びれと腹びれは、のちに四肢へ進化します。内耳は三半規管になって、3次元の世界へ。泌尿器系は中腎、生殖は卵生です。

## テーマ3　両生類
@roadmap 3
> 三つ目は、両生類です。

@board 両生類（水中から地上へ）
+ **肉鰭類** から両生類が生じた。**迷歯類** から爬虫類へ
+ からだ：二重の筒 ＋ 頭 ＋ 顎 ＋ **鰭 → 四肢**
+ 幼生（水中）から成体（陸上）へ **変態**
+! 心臓：**二心房一心室**
+ **鼓膜・鼓室**、**肺** の形成。**鼻腔** が口腔に通じる
+! 泌尿器系：**幼生は前腎、成体は中腎**　生殖：卵生
> 結論から。肉鰭類から両生類が生まれ、両生類の迷歯類から、爬虫類へつながります。からだは、ひれが四肢に変わった形。幼生は水の中、成体は陸の上へと変態します。心臓は、二心房一心室。鼓膜と鼓室、そして肺ができ、鼻腔が口の中に通じます。泌尿器系は、幼生が前腎、成体が中腎。生殖は卵生です。

## テーマ4　爬虫類
@roadmap 4
> 最後のテーマ。爬虫類です。

@board 爬虫類（完全な陸上生活）
+ 迷歯類 → **無弓類**（カメ）・**単弓類**（絶滅 → **哺乳類へ**）・広弓類（絶滅）・**二弓類**（ムカシトカゲ・恐竜・ワニ）
+ からだ：二重の筒 ＋ 頭 ＋ 顎 ＋ 四肢 ＋ **交接器**（**体内受精**）
+! 心臓：**二心房不完全二心室**（ヒトの心室中隔膜性部欠損症に似た形）
+ **尿膜**　泌尿器系：**後腎**　**殻付き卵** → **完全陸上生活**
> 結論から。迷歯類から、カメの無弓類、絶滅した単弓類、広弓類、そしてムカシトカゲや恐竜、ワニの二弓類が生まれました。哺乳類につながるのは、単弓類です。からだには交接器が足されて、体内受精になりました。心臓は、二心房、不完全二心室。ヒトの病気でいえば、心室中隔の膜性部が欠けた形に似ています。尿膜をもち、泌尿器系は後腎。そして殻のついた卵で、完全な陸上生活ができるようになりました。
!3

@figure heart
>[rept] 爬虫類は、二心房、不完全二心室。心室の壁が、まだ閉じきっていません。
>[mamm] 次の講で見る哺乳類で、ようやく二心房二心室になります。

@memo 覚え方 :: 心臓は **1-1 → 2-1 → 2-不完全2 → 2-2**。腎臓は **前 → 中 → 後**（両生類は幼生前腎・成体中腎、爬虫類で後腎）。
> 覚え方です。心臓は、1と1、2と1、2と不完全な2、そして2と2。腎臓は、前、中、後。爬虫類で後腎です。

@example 腎臓の3世代（補足） :: 講義資料の範囲外の補足：ヒトの発生でも、腎臓は **前腎 → 中腎 → 後腎** の順に現れ、最終的な腎臓は後腎からできる。第4講の「個体発生は系統発生を繰り返す」の例としてよく挙げられる。
> 一つ補足です。これは資料の外の話ですが、ヒトの発生でも、腎臓は前腎、中腎、後腎の順に現れて、最後の腎臓は後腎からできます。個体発生は系統発生を繰り返す、のよい例です。

## 今日のまとめ
@summary 今日覚えること
- **無顎類**（円口類）：顎なし、胸鰭・腹鰭なし、**二半規管**（2次元）、前腎＋中腎
- **有顎類**：**一心房一心室**、**三半規管**、中腎、卵生。**肉鰭類**（肺魚・シーラカンス）→ 両生類

- **爬虫類**：**二心房不完全二心室**、交接器（体内受精）、尿膜、**後腎**、殻付き卵。**単弓類 → 哺乳類**
> 最後に、今日のポイントです。
