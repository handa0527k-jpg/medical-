@board ヒトの染色体
+ **1956年** **Tjio & Levan**：ヒトの染色体数 **46本（23対）** を決定
+ **常染色体**・**性染色体**
+ 対になる2本 → **相同染色体**
> 1956年、TjioとLevanが、ヒトの染色体数を46本、23対と決定しました。染色体は、常染色体と、性染色体に分けられます。そして、対になる2本を、相同染色体といいます。
!1

@pitfall この2つは混同しやすい :: **娘染色体（染色分体）** ＝ 複製された **同じ** 染色体の2本。**相同染色体** ＝ **対になる** 2本の染色体。
> ここ、混同しやすいところです。娘染色体、染色分体は、複製された同じ染色体の2本。相同染色体は、対になる2本の染色体。言葉が似ているので、しっかり分けてください。

## テーマ2　有糸分裂の流れ
@roadmap 2
> 次は、有糸分裂の流れです。

@compare 有糸分裂の5つの時期
| 時期 | 起こること |
| **前期** | **染色質凝縮**・**核小体消失**・**中心体分離**・**紡錘糸形成** |
| **前中期** | **紡錘糸と染色体の結合**・**核膜消失** |
| **中期** | 染色体が **赤道板** 上に並ぶ |
| **後期** | **染色分体** の娘細胞への分離 |
| **終期** | **細胞質分離**・**核の再生** |
> 結論から。表で、順番に見ていきます。
>[1] 前期。染色質が凝縮し、核小体が消え、中心体が分離して、紡錘糸ができる。
>[2] 前中期。紡錘糸と染色体が結合し、核膜が消える。
>[3] 中期。染色体が、赤道板の上に並ぶ。
>[4] 後期。染色分体が、娘細胞へ分かれていく。
>[5] 終期。細胞質が分かれ、核が再生します。

@pitfall ここで間違えやすい :: スライドでは **核小体消失は前期**、**核膜消失は前中期**。「前期に核膜が消える」と覚えると、選択肢で迷う。
> ここ、間違えやすいところです。何がいつ消えるか。核小体は前期、核膜は前中期。この講義資料では、そう区切っています。

@anim mitosis
> 実際に、見てみましょう。
>[s1] 登場するのは、核膜、核小体、ほどけた染色質、そして中心体です。
>[s2] 前期。染色質が凝縮して、染色体になります。核小体が消えて、中心体が両極へ分かれ、紡錘糸ができていきます。
>[s3] 前中期。核膜が消えて、紡錘糸が、染色体の動原体に結合します。
>[s4] 中期。染色体が、赤道板の上に、一列に並びます。
>[s4!] 箱を中央に、きれいに並べた状態です。
>[s5] 後期。染色分体が分かれて、両極へ引かれていきます。
>[s6] そして、極と極そのものも離れていく。この2つの動きは、テーマ3で詳しくやります。
>[s7] 終期。細胞質が分かれて、それぞれに核が再生します。

>[m2] 核小体消失、
>[m3] 中心体分離、

>[m5] 前中期は、紡錘糸と染色体の結合、
>[m6] 核膜消失。
>[m7] 中期は、赤道板上に並ぶ。
>[m8] 後期は、染色分体の娘細胞への分離。

## テーマ3　染色体と紡錘糸
@roadmap 3
> 最後のテーマ。染色体と紡錘糸です。

@board 染色体の紡錘糸への結合
+ 紡錘糸は **セントロメア** の **動原体** に結合（**動原体微小管**）
> 紡錘糸は、染色体のセントロメアにある、動原体に結合します。この微小管を、動原体微小管といいます。
+ 分離には **2種類の動き**
+ **後期A**：**染色体が極に向かって** 移動
+ **後期B**：**極と極が離れる** 移動
> そして、染色体の分離には、2種類の動きが関わっています。後期Aは、染色体が、極に向かって移動する。後期Bは、極と極そのものが、離れていく。
!5
!6

@memo 覚え方 :: **A＝染色体が動く、B＝極が動く**。荷物を引き寄せるのがA、引き綱の起点ごと離れるのがB。
> 覚え方です。Aは染色体が動く。Bは極が動く。荷物を引き寄せるのがA、引き綱の起点ごと離れていくのがBです。

@figure chrm
>[kmt] 図では、この緑の線が、動原体微小管。
>[kin] 動原体を、両側から引いています。

@slide 20

>[m2] そして右の図。染色体の分離に関与する2種類の動き。上から、後期Aで染色体が極へ、後期Bで極と極が離れていきます。

## 今日のまとめ
@summary 今日覚えること
- 染色体：**短腕・長腕・セントロメア・動原体・染色分体**。**46本（23対）**、1956年 Tjio & Levan
