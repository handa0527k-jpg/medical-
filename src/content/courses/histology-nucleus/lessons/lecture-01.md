## テーマ2　光学顕微鏡で見る核
@roadmap 2
> 次の問いです。光学顕微鏡で、核はどのように見えるか。

@board 染色の鍵は「何と結合するか」
+ **ヘマトキシリン**（青〜紫） → **酸性基**（DNA, RNA）
+ **エオジン**（ピンク） → **塩基性基**（蛋白質）
> 結論から。HE染色のヘマトキシリンは、酸性基、つまりDNAやRNAと結合して、青から紫に染めます。エオジンは、塩基性基、つまり蛋白質と結合して、ピンクに染めます。
+ **メチルグリーン**（緑） → **DNA（二本鎖）**
+ **ピロニン**（ピンク） → **RNA（一本鎖）**
> もう一つの染色、メチルグリーン・ピロニン染色、略してMP染色では、メチルグリーンがDNA、二本鎖と結合して緑に。ピロニンがRNA、一本鎖と結合してピンクに染めます。
!3
!4

@board では、核の中身は？
+ 染色質：**DNA が多い**
+ 核小体：**RNA が多い**
+ 細胞質：**蛋白質とRNAが多い**
> では、核の中身はどうか。染色質はDNAが多い。核小体はRNAが多い。細胞質は、蛋白質とRNAが多い。
+ ↓ HE：染色質も核小体も **H**、細胞質は **E**
+ ↓ MP：染色質は **MG**、核小体と細胞質は **PY**
> だから、HE染色では、DNAもRNAも酸性基なので、染色質も核小体もヘマトキシリン。細胞質はエオジン。一方MP染色では、DNAの多い染色質がメチルグリーン、RNAの多い核小体と細胞質がピロニンになります。

@compare スライド5の表
| | HE染色 | MP染色 |
| 染色質 | **H**（ヘマトキシリン） | **MG**（メチルグリーン） |
| 核小体 | **H**（ヘマトキシリン） | **PY**（ピロニン） |
| 細胞質 | **E**（エオジン） | **PY**（ピロニン） |
> スライドの表を、もう一度。
>[1] 染色質は、HとMG。
>[2] 核小体は、HとPY。
>[3] 細胞質は、EとPY。

@pitfall ここで間違えやすい :: 「核小体は核の中だから **緑**」は誤り。MP染色が見分けるのは **DNAかRNAか**。核小体はRNAが多いので **ピロニン（ピンク）**。
> ここ、間違えやすいところです。核小体は核の中にあるから、緑。これは誤りです。MP染色が見分けているのは、場所ではなく、DNAかRNAか。核小体はRNAが多いので、ピンクです。

## テーマ3　電子顕微鏡で見る核
@roadmap 3
> 三つ目の問いです。電子顕微鏡で、核の構造の何が明らかになったか。

@board 電顕で分かったこと
+ 核膜は **2枚**：外核膜 → **核周囲腔**（核膜槽） → 内核膜
+ 2枚が合わさる所に **核膜孔**
> 結論から。まず、核膜が2枚の膜だということです。外側から、外核膜、核周囲腔、別名、核膜槽、そして内核膜。2枚が合わさった所に、核膜孔が開いています。
+ 染色質：**正染色質**（明るい）／**異染色質**（核膜下・核小体付随）
> 染色質は、明るく見える正染色質と、電子密度の高い異染色質に分かれます。異染色質は、核膜の下と、核小体のまわりに見られます。
+ 核小体：**線維中心・線維部・顆粒部**
> そして核小体は、線維中心、線維部、顆粒部の、3つの区画に分かれます。

> 覚え方です。核膜は、外、すき間、内。外核膜、核周囲腔、内核膜。名前がそのまま、位置を表しています。
