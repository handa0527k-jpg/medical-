## テーマ1　細胞の部屋リスト
@roadmap 1
> 最初は、部屋のリストです。

@board 細胞の構成要素
+ 細胞 = 細胞膜 ＋ **細胞質** ＋ 核
> まず結論です。細胞は、細胞膜と、細胞質と、核からできています。
+ 細胞質 = **小器官** ＋ **封入体** ＋ **サイトゾル**
> その細胞質の中身が、小器官、封入体、そしてサイトゾルです。
+ ↓ 小器官：**膜性**（部屋） | **非膜性**（機械）
> 小器官は、さらに二つに分かれます。膜で囲まれた膜性小器官と、膜のない非膜性小器官。工場でいえば、部屋と、機械です。
+! 非膜性 = **リボソーム** と **細胞骨格** だけ
> ここ、覚えてください。非膜性は、**リボソーム**と**細胞骨格**の二つだけです。

@point ここは試験で狙われます :: **核膜**は膜性小器官に数える。でも**核そのもの**は小器官と呼ばない。
> ここは選択肢で狙われやすい一文です。
> 核膜は小器官の仲間。核そのものは小器官ではない。核は工場の本社であって、工場の一部屋ではない、とイメージしてください。

## テーマ2　超遠心法
@roadmap 2
> 次のテーマです。目に見えない部屋の仕事を、研究者はどうやって突き止めたのか。

@board 超遠心法
+ 細胞をすりつぶす → **ホモジネート**
> 結論から言います。1950年代、研究者は細胞をすりつぶして、遠心機にかけました。すりつぶした液が、ホモジネートです。
+ 回転を強くする → **重いものから順に沈む**
> なぜ分けられるのか。回転を少しずつ強くしていくと、重いものから順に、底へ沈むからです。
+ 1,000×g → **核**
+ ↓ 1万×g → **ミトコンドリア・リソソーム**
+ ↓ 10万×g → **ミクロゾーム**
+ ↓ 最後の上清 → **サイトゾル**
> 順番に書きます。千ジーで核。1万ジーで、ミトコンドリアとリソソーム。10万ジーで、ミクロゾーム。そして、最後に残った上清がサイトゾルです。
!6

@anim cent
> では、実際に遠心管の中で何が起こるのか、見てみましょう。
>[s1] 細胞にズームインします。中には、大きさの違う小器官が並んでいますね。
>[s2] まず、細胞膜を壊して、すりつぶします。小器官が液体の中に放り出されて、全部が混ざったホモジネートになります。
>[s3] 遠心管の中です。粒の大きさが違うことに注目してください。
>[s4] 最初は、弱い遠心力。千ジーです。
>[s4] いちばん大きくて重い核だけが、底に沈んでいきます。
>[s4!] 沈んだのは、核だけ。ほかの小器官は、まだ上の液体に残っています。
>[s5] 上清だけを、次の管に移します。
>[s6] 次は1万ジー。中くらいの力で、ミトコンドリアとリソソームが沈みます。
>[s7] さらに上清を回して、10万ジー。今度はミクロゾームが沈みます。
>[s7!] ミクロゾームの正体は、すりつぶしたときにちぎれて小さな袋になった、小胞体のかけらです。
>[s8] 三回の遠心で、大きいものから順に分けられました。最後の上清が、サイトゾルです。
>[s9] 左が、全部混ざったホモジネート。右が、遠心力を上げながら分けた結果です。
>[s10] 分けた成分を、生化学的にも、形のうえでも調べる。こうして、それぞれの小器官の機能が明らかになりました。

@pitfall この言葉に注意 :: **ミクロゾーム**という小器官は存在しない。すりつぶしてできた**小胞体のかけら**を、実験上そう呼んでいるだけ。
> ここで一つ注意してください。
> ミクロゾームという名前の小器官が、細胞の中にあるわけではありません。すりつぶしたときにできる小胞体のかけらを、実験上そう呼んでいるだけです。

@example たとえるなら :: 洗濯機の脱水。弱く回すと大きな**石**、強く回すと**砂**、もっと強く回すと**泥**が沈む。最後に残る濁った水が**サイトゾル**。
> イメージで覚えましょう。洗濯機の脱水です。
> 弱く回すと石が沈む。強く回すと砂。もっと強く回すと泥。最後に残る濁った水が、サイトゾルです。

@slide 10
> スライド10で確認します。
>[m1] 1950年代。
>[m2] 細胞を破壊したホモジネートを、
> 千ジーで沈殿するのが、核。
>[m3] 1万ジーで、ミトコンドリアと、リソソーム。
>[m4] 10万ジーで、ミクロゾーム。
>[m5] 主に小胞体です。
>[m6] そして上清が、サイトゾル。

@quiz q018 typical
> では、典型的な問題を見てみましょう。今日の知識と、少し先の知識をつなげる問題です。
> ホモジネートを1万ジーで遠心した沈殿から、酸性で働く加水分解酵素の活性が検出された。この結果を説明する小器官は、どれでしょう。まず自分で考えてみてください。
@think 18
@explain
>[q] この問題文で注目するのは、二つ。「1万ジーの沈殿」と、「酸性で働く加水分解酵素」です。
> 1万ジーの沈殿といえば、ミトコンドリアとリソソーム。ここで候補が二つに絞れます。
>[B] そのうち、酸性の加水分解酵素を持つ袋は、リソソーム。正解はBです。
>[A] Aの核は、千ジーで沈みます。
>[C] Cのミクロゾームは、10万ジー。
>[E] Eのサイトゾルは、10万ジーの上清ですね。
>[D] Dのリボソームは、酵素の袋ではありません。
> 「どの遠心力で沈んだか」で候補を絞って、「何の酵素か」で決める。この二段階が、この問題の解き方です。

## テーマ3　社内郵便
@roadmap 3
> 三つ目のテーマです。部屋どうしのつながり。

@board 細胞内膜系
+ 膜性小器官の膜 = 細胞膜と同じ **単位膜**
> まず結論です。膜性小器官の壁は、どれも細胞膜と同じ、単位膜でできています。
+ 部屋どうし → **小胞**（封筒）でつながる → 細胞膜
> そして部屋と部屋は、小胞という封筒をやりとりしてつながり、最後は細胞膜ともつながる。これをまとめて、**細胞内膜系**と呼びます。
+! 小器官の内腔 ＝ **細胞の外**と機能的に連続
> ここで、第1講の「袋の中は外」を思い出してください。封筒でやりとりしているので、小器官の内腔も、細胞の外と機能的につながっているんです。

@slide 11
> スライド11を見てください。
>[m1] 細胞内膜系は、膜性小器官の膜の総称。
>[m2] 形質膜と同じ、単位膜構造。
>[m3] 小胞性輸送によって、形質膜と連続する。
>[m4] そして、内腔は細胞外と機能的に連続する。
> 左の図をよく見ると、封筒には種類があります。

@compare 封筒の種類
| 便 | 被覆 |
| 粗面小胞体 → ゴルジ（行き） | **COP-II** |
| ゴルジ → 粗面小胞体（戻り） | **COP-I** |
| ゴルジの出口（TGN）から先 | **クラスリン** |
>[1] 粗面小胞体からゴルジへ向かう行きの便が、COP-II。
>[2] ゴルジから戻る便が、COP-I。
>[3] ゴルジの出口、TGNから先の便には、クラスリンが使われます。

@memo 覚え方 :: **ツー（II）で行って、ワン（I）で戻る**。
> 覚え方です。ツーで行って、ワンで戻る。
> 数字が大きいほうが行き。これだけで、行きと戻りの入れ替えのひっかけは防げます。

## テーマ4　本館と別棟
@roadmap 4
> 最後のテーマです。

@board 本館と別棟
+ 本館：小胞体・ゴルジ・分泌小胞・リソソーム・エンドソーム・**核膜**
> 小胞体、ゴルジ、分泌小胞、リソソーム、エンドソーム、そして核膜。これらは、蛋白質を作って、運んで、出す流れ作業でつながった本館です。
+ ↓ 作る → 運ぶ → 出す（郵便網でつながる）
+! 別棟：**ミトコンドリア** と **ペルオキシソーム**
> ところが、ミトコンドリアとペルオキシソームだけは、この郵便網のどこにもつながっていない、別棟です。
_1
> 核膜は本館側、というのもポイントです。

## 今日のまとめ
@summary 今日覚えること
- 細胞質 ＝ 小器官（膜性・非膜性）＋封入体＋サイトゾル。非膜性は**リボソームと細胞骨格**
- 核膜は小器官、**核は小器官ではない**
- 1,000×g **核** → 1万×g **ミト・リソ** → 10万×g **ミクロゾーム**（小胞体のかけら）→ 上清 **サイトゾル**
- 別棟は **ミトコンドリア** と **ペルオキシソーム**
> 最後に、今日のポイントです。
>[1] 細胞質の分類。非膜性はリボソームと細胞骨格だけ。
>[2] 核膜は小器官、核は小器官ではない。
>[3] 遠心力と沈むもの。千ジーで核、1万ジーでミトコンドリアとリソソーム、10万ジーでミクロゾーム、上清がサイトゾル。
>[4] そして、別棟の二つ。
> この4つが分かっていれば、今日はOKです。
