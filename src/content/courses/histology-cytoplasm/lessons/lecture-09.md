## テーマ2　サイトゾル
@roadmap 2
> 二つ目のテーマ。作業場の床です。

@board 細胞質基質
+ 電子顕微鏡で見ても **無構造** の部分
+ ↓ 生化学的には **サイトゾル** ＝ **10万×g 遠心の上清**
> 電子顕微鏡で見ても、何の構造も見えない部分を、細胞質基質といいます。生化学的には、サイトゾルと呼びます。
> そして、ここで第2講とつながります。遠心分離で、最後に残った上清。10万ジーの上清が、サイトゾルでした。
!2

@board サイトゾルの中身
+ **遊離リボソーム** で作られたサイトゾル蛋白
+ 種々の **酵素** 蛋白
+ **脱重合した細胞骨格** の蛋白（構造蛋白）
+ 塩類・**イオン** → **浸透圧**・**pH** の恒常性
+ そして **水**（H₂O）
> 中身は、豊かです。遊離リボソームで作られたサイトゾル蛋白。いろいろな酵素。脱重合した細胞骨格の材料、つまりばらばらになったアクチンやチュブリンですね。そして、塩類やイオンが、浸透圧とpHを一定に保っています。もちろん、主成分は水です。

@pitfall ひっかけに注意 :: サイトゾル蛋白は **遊離リボソーム** で作る（付着リボソームではない）。**膜の中**にあるもの（ミトコンドリアの基質顆粒など）はサイトゾルではない。
> ここは、ひっかけが出やすいところです。サイトゾル蛋白を作るのは、遊離リボソーム。第3講の、荷札のない蛋白でしたね。そして、膜の中にあるもの、たとえばミトコンドリアの基質顆粒は、サイトゾルではありません。

@quiz q108 typical

@think 15
@explain
>[q] 「挙げられていないもの」を選ぶ問題です。一つだけ、別の場所のものが混ざっています。
>[E] 正解はE。ミトコンドリアの基質顆粒は、ミトコンドリアの中、膜の内側にあります。
>[A] Aの、遊離リボソームで作られたサイトゾル蛋白。挙げられています。
>[B] Bの酵素、
>[C] Cの脱重合した細胞骨格の蛋白、
>[D] Dの塩類とイオンも、すべて挙げられています。
> 膜の中にあるものは、サイトゾルではない。この一言で解けます。

## テーマ3　工場一周の総まとめ
@roadmap 3
> 最後に、9回分の総まとめです。

@figure cell
> 細胞全体の地図で、工場を一周しましょう。
>[mem] まず、門、細胞膜。ここから物が出入りします。
>[nuc] 核から設計図が出て、
>[rer] 粗面小胞体の製造ラインで、分泌蛋白や膜蛋白が作られます。
>[ser] 滑面小胞体では、脂質の合成や解毒。
>[gol] ゴルジ装置は、出荷センター。修飾して、行き先ごとに仕分けます。
>[sec] 分泌顆粒に詰めて、外へ出荷。
>[end] 外から取り込んだものは、エンドソームを経て、
>[lys] リソソームの処理場で分解されます。
>[mit] 郵便網から離れた別棟、発電所のミトコンドリアと、
>[per] 化学処理室のペルオキシソーム。
>[cen] 中心体からは、
>[mt] 微小管の道路が放射状に伸び、
>[act] 膜の裏をアクチンが補強し、
>[if] 中間径フィラメントの鉄筋が、張力に耐えます。
>[rib] そして、すき間の床、サイトゾルでは、遊離リボソームが、サイトゾル蛋白を作っています。
>[cyt] ここが、今日の作業場です。

@compare 工場一周・キーワード
| 場所（たとえ） | 決め手のキーワード |
| 細胞膜（門） | **脂質二重層**・エンドサイトーシス |
| 粗面小胞体（製造ライン） | **シグナル配列**・付着リボソーム |
| ゴルジ装置（出荷センター） | **シス → トランス → TGN** |
| リソソーム（処理場） | **酸性の加水分解酵素** |
| ミトコンドリア・ペルオキシソーム（別棟） | **ゴルジを通らない** |
| 細胞骨格（骨組みと道路） | **5〜7・10・25 nm** |
| サイトゾル（床） | **10万×g の上清** |
> 表で、もう一度だけ振り返ります。
>[1] 細胞膜は、門。
>[2] 粗面小胞体は、シグナル配列で決まる製造ライン。
>[3] ゴルジは、シスからトランス、TGNへ進む出荷センター。
>[4] リソソームは、酸性の加水分解酵素の処理場。
>[5] ミトコンドリアとペルオキシソームは、郵便網を通らない別棟。
>[6] 細胞骨格は、ゴーナナ、ジュウ、ニコ。
>[7] そしてサイトゾルは、10万ジーの上清。

@point 最後に :: 白紙に、この工場の地図を **自分で描けたら** 合格。部屋・道路・床の **つながり** で覚えると、選択肢の入れ替えに強くなる。
> 最後に、一つだけ。白紙に、この工場の地図を、自分で描いてみてください。部屋と、道路と、床。ばらばらの暗記ではなく、つながりで覚えておくと、選択肢の入れ替えに、ぐっと強くなります。

## 本番問題
@quiz q107 final
> では最後に、今日の内容をまとめて確認する問題です。
> 細胞小器官以外の細胞質成分について、正しいものはどれか。
@think 18
@explain
>[q] この問題は、封入体とサイトゾルの両方を聞いています。第2講と第3講の知識も、ここでつながります。
>[B] 正解はB。封入体には、脂肪滴、グリコーゲン顆粒、メラニン顆粒などの色素が含まれます。
>[A] Aは、封入体を細胞小器官の一種としています。小器官以外の成分です。
>[C] Cは、細胞質基質が電顕で明瞭な構造を示す。無構造です。
>[D] Dは、サイトゾルを千ジー遠心の沈殿としています。千ジーで沈むのは核。サイトゾルは、10万ジーの上清です。
>[E] Eは、サイトゾル蛋白を付着リボソームで産生。遊離リボソームです。
> 遠心の順番と、リボソームの使い分け。これまでの講義の知識で、全部の選択肢が判断できます。
