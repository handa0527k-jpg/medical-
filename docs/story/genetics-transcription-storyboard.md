# 絵コンテ：「写字室の朝」（遺伝医学「転写（機構と疾患）」ストーリーアニメ）

「設計図の図書館」（`genetics-basics` のストーリーアニメ）のつづき。登場人物・舞台・たとえの規則はそのまま引き継ぐ。

- **ジン（僕）**：見習い司書。語り手。深緑のカーディガン、丸眼鏡、帆布の鞄
- **原本の番人デオ**：DNA＝設計図の原本。原本は館外に出さない
- **編集者スプラ**：写字室の編集者（スプライシング）。銀のはさみ
- **糸巻きのオクタ**（ヒストン）・**付箋屋のメチ**（エピゲノム）：書庫の場面に少しだけ登場
- 新しく加える人物（既存の人物は変えない）
  - **写字係ポル**：本館の写字係＝**RNAポリメラーゼII**。水色の上着（講義資料の図のポリメラーゼの色）、栗色のポニーテール
  - **分館の写字係コア**：細菌の**コア酵素**。同じ水色の上着の小柄な青年
  - **案内係シグマ**：細菌の**σ因子**。オレンジのたすきをかけた少年。十文字書けたら仕事を終えて離れる

## 物語の目的

一枚の閲覧票（「肝臓の窓口から、グルコキナーゼの写しを一部、正午まで」）を届けるまでの半日。
**写す（転写）→ 整える（プロセシング）→ 届ける（核外輸送）**を一続きの物語にし、各場面の出来事が次の場面のきっかけになるようにする。

詳しい分子の手順は機序アニメ（template / bacteria / lac / euinit / clock / splice / mirna）に任せ、
ストーリーでは「何が起きるのか」と「なぜ次へ進むのか」を見せる。

## 一貫させる約束（連続性）

| 項目 | 約束 |
|---|---|
| 時刻 | 朝8時（開館前）→ 正午。場面ごとに時計を映し、光の色を朝→昼に移す |
| 光源 | 本館は**画面左の高窓からの朝日**（キーライト左）。分館は天窓（真上）。写字室は左の窓＋卓上ランプ |
| 向き | 転写・写しは常に**画面の左→右**（RNAは右へ5'→3'に伸びる）。ジンは窓口（画面右）へ向かって進む |
| 色 | 非鋳型鎖＝黄、鋳型鎖＝青、RNA（写し）＝ピンク、ポリメラーゼ＝水色、σ＝オレンジ（機序アニメと同じ） |
| 持ち物 | 閲覧票はジンの右手→鞄。写しは**ピンクの紙の帯**（場面2〜7で同じ帯が長くなり、整えられ、窓口へ） |
| たとえと実際 | 図書館の場面＝たとえ。分子の図は青い方眼紙の差し込みに描き、左上に「**実際の細胞では**」の札を必ず付ける |
| 原核と真核 | 分館＝細菌（原核生物）、本館＝ヒト（真核生物）。差し込みの右上に「細菌（原核生物）」「ヒト（真核生物）」の札 |

## 場面

### 1. 朝の閲覧票（約1分）
- **目的**：舞台と依頼。セントラルドグマと「転写」が最初の一歩であること（スライド3・4・5）
- **動き**：朝日の図書館の外観 → 本館の広間、ジンが入ってくる（左→右へ歩く）→ デオが閲覧票を差し出す（予備動作で腕を引き、差し出し、受け取ったあとに紙が少し揺れる）→ 写字係ポルが振り向く
- **ナレーション／セリフ**：「あの雨の夜のあと…」／デオ「肝臓の窓口からだ。グルコキナーゼの写しを一部、正午まで」／ポル登場
- **差し込み**：DNA →（転写）→ RNA →（翻訳）→ タンパク質
- **つながり**：「どこから、どちら向きに写すか」→ 原本の書見台へ

### 2. 鏡の向きで写す（約1分20秒）
- **目的**：鋳型鎖と非鋳型鎖、3'→5'に読み5'→3'に書く、TのかわりにU、リン酸ジエステル結合、プロモーターが向きを決める（スライド7・8・10・11）
- **動き**：書見台に二段の原本。ポルの指が下段（鋳型鎖）を右へなぞり、ペン先からピンクの帯が右へ伸びる。ジンが身を乗り出す
- **差し込み**：二本鎖・ポリメラーゼ・伸びるRNA（5'端を左、3'端を右に固定表示）、NTP → ピロリン酸
- **つながり**：ポル「本館の受付は手続きが多いの。仕組みをつかむなら、まず分館を」→ 分館へ

### 3. 分館の写字係（約2分）
- **目的**：細菌の転写サイクル（ホロ酵素、−35・−10、約10ヌクレオチドでσが離れる、伸長、ステムループ・ρで終結）とlacオペロン（負→正の順）（スライド14〜20・24・25）
- **動き**：天窓の小部屋。シグマがコアの肩に乗って目印を探す → コアが書き始め、十文字でシグマが飛び降りる → 帯の端が折れ返ってループになり、コアの手が止まる → 棚のラクトースの本には「写すな」の札（リプレッサー）→ 札が外れ、「写せ」の呼び込み係（cAMP–CRP）が来て3ページを一続きに写す
- **つながり**：シグマ「本館では、ぼく一人じゃ足りないんだって」→ 本館へ戻る

### 4. 本館の受付（約2分）
- **目的**：真核生物の転写開始（TATAボックス、TFIID/TBP、TFIIB、ポリメラーゼIIと残りの因子、TFIIHがほどいてCTDをリン酸化）、クロマチンをほどく助け、エンハンサーとサイレンサー、グルコキナーゼの組織別プロモーター（スライド28〜35・49）
- **動き**：グルコキナーゼの巻はきつく巻かれている → オクタが糸巻きをゆるめ、メチが付箋を貼り替える → 受付台に案内係たちが順に並び、最後にポルが着席 → 出発の合図でポルが右へ書き出す。遠くの棚から「急ぎ」の札（エンハンサー）が届く
- **つながり**：書き上がった長い写し（前駆体）がスプラの写字室へ

### 5. 写しを整える（約1分40秒）
- **目的**：mRNA前駆体 → 5'キャップ・スプライシング（GU…AG、スプライセオソーム、投げ縄）・ポリA → 選択的スプライシング（スライド46〜52）
- **動き**：スプラが帯の頭に帽子（キャップ）、はさみでイントロンを切り、輪になって落ちる（投げ縄）→ エクソンを貼り合わせ、尾に印（ポリA）
- **つながり**：スプラ「さあ、門へ」→ 窓口へ

### 6. 写しにならない写し（約1分10秒）
- **目的**：ncRNA（rRNA・tRNA・miRNA・lncRNA）、疾患（Prader-Willi症候群、Feingold症候群）（スライド55・56・67・68）
- **動き**：窓口へ向かう廊下。館の中で働きつづける写しの棚。デオが一冊を指さす
- **つながり**：正午の鐘

### 7. 正午の窓口（約1分40秒）
- **目的**：核外輸送、時計遺伝子のフィードバックと疾患（マウスの所見）、ミトコンドリアの転写、まとめ（スライド41〜43・46・70〜72）
- **動き**：ジンが写しを門（核膜孔）に通す → 大時計が正午を打つ → 時計の中の歯車（BMAL1–CLOCK ⇄ Per・Cry）→ 別冊の写字係 → デオとジンの会話、外の昼の光
- **終わり**：題名と出典・クレジット

## 音

- 声：ナレーター（ジン）と各人物。日本語の音声合成（edge-tts、既存の「設計図の図書館」と同じ声の設定）。医学用語は `say` で読みを指定
- 音楽：明るく希望のある曲（利用条件が明確なもの）。セリフ中は自動で下げる（下敷きの音に焼き込む）＋プレーヤーでBGMの再生・停止と音量を操作できる
- 効果音：紙、ペン、足音、鐘、扉。説明の邪魔をしない小さめの音量
