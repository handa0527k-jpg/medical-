# 設計図の図書館 ― 場面構成と絵コンテ（改訂案）

対象：遺伝医学「遺伝子の基礎」のストーリーアニメ（アニメ画面）。授業動画・講義プレーヤーは対象外。

## 現状（改訂前）

- 9場面・66セリフ・約12分17秒。Canvas 2D の手描き風（`story/draw.ts`）＋ 1本にまとめた音声（`story.mp3`）。
- 人物は丸い二頭身（顔と服の区別なし）。背景はほぼ静止した本棚。カメラ移動・演技・光の変化はほぼない。
- 各場面は「キャラクターが現れて説明する」形で独立しており、場面どうしの因果はない。
- 冒頭（library 0〜44秒）：本棚の背景にタイトル → ジンが歩いて入る → デオが規則を言う。目的・異変・引きがない。
- 字幕が画面下の人物と重なる。

## 物語の軸（全編）

- **主人公**：ジン（僕）。見習い司書。初めての夜勤。
- **目的**：閉館後に届いた閲覧票「二日酔いの番人（ALDH2）の写しを一部。午前六時まで」を、夜明けまでに正しく写して届けること。
- **ルール**（デオ）：原本は持ち出さない。必要なページだけを写す。
- **モチーフ**（場面をまたいで繰り返し、終盤で回収）
  - 閲覧票（ジンの胸ポケット）……最後に「済」の印が押される
  - 落ちてきた1ページ（文字が1つかすれている）……相補性で復元 → 元の巻へ戻す
  - デオの真鍮のルーペ、緑の卓上ランプ、時計（23:00 → 6:00）
  - デオの二重らせん模様のマフラー
- **変化**：「文字を書き写せばよい」と思っていた僕が、「設計図は、どう読まれるかで意味が決まる」と知って朝を迎える。

### 一貫させる設定

- **ジン**：20歳前後、細身・約6.8頭身。焦げ茶の短髪（つむじのはね毛1本）、細い丸眼鏡。白シャツ、深緑のカーディガン、紺のズボン、茶色の靴。帆布の肩掛け鞄（右肩→左腰）。外では紺の傘。閲覧票は受け取った後、左手に持つ。
- **デオ**：高齢、長身・約7.2頭身。後ろへ流した銀髪、短いひげ、半月形の眼鏡。炭色の長いコート。赤と青の二重らせん模様のマフラー。首から真鍮のルーペ。
- **位置と向き**：ジンは常に**画面左→右**へ進む。デオは画面右側、机の奥。
- **光**：館内はランプの琥珀色（主光）と高窓の青い月明かり（補助光）。外は雨の青と窓の琥珀色。
- **時刻**：外観の時計23:00、受付の置時計23:04。

## 音声

- 声：Microsoft Edge のニューラル音声（edge-tts、APIキー不要）。特定の実在人物の声は使わない。
- 語り：落ち着いた低めの声、少し遅め（-6Hz、-10%）。文を短く分け、読点で息継ぎ、場面の間は無音の「間」（`wait`）で作る。
- 読みの指定：DNA→ディーエヌエー、ゲノム→ゲノム、ALDH2→エーエルディーエイチツー（既存の読み規則）。必要な行は `say` で個別に指定。
- 音声が再生できないときも、字幕と画面だけで進む（既存の動作）。

## 実装メモ（試作）

- 冒頭は新しい場面 `opening`（約47秒）。以降の8場面は従来の絵とセリフのまま（library は冒頭と重なる3行を削除し、絵のタイミングを詰めた）。
- 絵：`src/content/courses/genetics-basics/story/opening.ts`（6カット）、`cast.ts`（ジンとデオの見た目を1か所で定義）。
  共通の道具：`src/engine/story/rig.ts`（人物：頭身・顔・髪・服・歩行・呼吸・まばたき・視線・腕のIKでつかむ・口の動き）、
  `src/engine/story/cine.ts`（予備動作／行き過ぎて戻るイージング、カメラ、光の柱、埃、雨、被写界深度、粒子感、色調）。
  他の教材のアニメはこれらを読み込まないので影響しない。
- カット割りはセリフの開始時刻（キュー）から計算する。声を録り直しても絵と字幕と口の動きがずれない。
- 絵は再生位置だけで決まる（乱数も固定）。同じ時刻は常に同じフレームになる。

### 見方

- アプリ：遺伝医学「遺伝子の基礎」→ アニメ →「設計図の図書館」→ 上映をはじめる。
- 位置を指定して開く：`#/open/genetics-basics/animations/story?t=12.5`（その位置の絵を表示し、再生するとそこから続く）。
- 静止画の書き出し（開発用）：`npx vite --port 5199` を起動して
  `node scripts/story-frames.mjs genetics-basics out/ --from 0 --to 47 --fps 4 --sheet`
  （`--at 3,12,37.9` で任意の時刻、`--phone` でスマホ幅、`--no-subs` で字幕なし）。

### 音声の設定

- `story.json` の `voices`（話者ごとの声・ピッチ・速さ）。行ごとに `tone: [pitch, rate]` で調子、`say` で読み、`wait` で行の前の無音（秒）を指定できる。
- 録音：`npx tsx scripts/build-story-speech.ts genetics-basics` → `python3 scripts/generate-story-audio.py genetics-basics`（変わった行だけ録り直す）。
- 読みの確認：`python3 scripts/check-story-audio.py genetics-basics`。
- 音声エンジンは edge-tts（Microsoft のニューラル音声、APIキー不要）。別の有料TTSに替える場合は、キーを環境変数から読む形で `generate-story-audio.py` の `synthesize()` を差し替える。
