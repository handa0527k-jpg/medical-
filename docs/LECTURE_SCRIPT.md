# 授業台本（予備校スタイル）の書き方

授業モードは「PDFを読み上げるアプリ」ではなく「講師の授業を受けるアプリ」です。各講義は
`src/content/courses/<course>/lessons/lecture-NN.md` の **台本** から生成されます。
台本がない講義は、従来どおり教科書から自動生成（`scripts/lib/lecture-builder.ts`）されます。

```
npm run build:narration                          # 台本 → narrations/lecture-NN.json
python3 scripts/generate-audio.py <course>       # 変わった文だけ録り直し（docs/AUDIO.md）
```

## 基本の考え方

- `>` で始まる行が **講師のセリフ**（1行 = 字幕1枚 = 音声1文）。
- `@…` と `+…` は **画面の指示**（ト書き）。指示は次のセリフから効き、声と画面が同期します。
- 講師はオリジナルのキャラクターです。実在の予備校・講師の口調や決め台詞は使いません。
- 内容は PDF（スライド・教科書本文）に書かれていることだけ。試験の出題傾向などを創作しません。
  授業資料外の補足は `@example` などのカードで「たとえ」「臨床では」と明示します。

## 推奨の流れ（1講あたり）

```
## 導入        @title → @goals（今日押さえてほしい3つ）
## 全体像      @cellmap / @figure / @anim で全体図 → @roadmap（学習マップ）
## テーマN     @roadmap N → @board（結論→理由→仕組み）→ @slide（根拠）→ @compare / カード
               → @quiz check（確認）/ typical（典型問題：考え方から解説）
## 今日のまとめ @summary（「この○つが分かっていればOK」）
## 本番問題    @quiz final（講義全体を統合する1問）
@end           → 終了レポート（理解度・正答率・間違えた問題・復習リンク）
```

## 指示一覧

| 指示 | 画面 | セリフ側のフォーカス |
|---|---|---|
| `## 名前` | セクション（タイムラインのチャプター、レポートの復習リンク） | |
| `@title` | タイトル画面 | |
| `@goals 見出し` / `@summary 見出し` + `- 項目` | 目標 / まとめのリスト | `>[2]` 2番目を強調 |
| `@roadmap 見出し` + `- 項目` / `@roadmap 2` | 学習マップ（2回目以降は番号で現在地） | `>[3]` |
| `@cellmap 3` | 細胞全体図で第3講の領域を強調 | |
| `@board 見出し` | 板書（黒板） | |
| `+ 文` / `+! 文` | 板書に1行書く / 枠で囲んだ行 | `→` は矢印、`+ ↓ 文` は下向きの展開、`A \| B` は対比行 |
| `!2` / `_2` | 2行目を枠で囲む / 下線（次のセリフで） | |
| `@slide 12` | PDFスライド | `>[m3]` マスク3へカメラが寄る |
| `@figure id` | インタラクティブ図 | `>[gol]` 構造をハイライト |
| `@anim id` | 機序アニメーション | `>[s3]` ステップ3を再生、`>[s3!]` 最終フレームで止める |
| `@compare 見出し` + `\| … \|` 行 | 比較表（1行目は見出し） | `>[2]` 本文2行目を強調 |
| `@point` `@pitfall` `@memo` `@example` `ラベル :: 本文` | 重要ポイント / 混同注意 / 覚え方 / 具体例カード | |
| `@quiz q007 check\|typical\|final` | 5択問題（A–E、答えは出さない） | |
| `@think 15` | 無音の考える時間（カウントダウン。「解説へ ▶」で飛ばせる） | |
| `@explain` | 解説 | `>[q]` 問題文、`>[C]` 選択肢C（言及した順に正誤を表示） |
| `@end` | 終了 → レポート | |

インライン：`**強調**`、`{内腔|ないくう}`（表示は「内腔」、読みは「ないくう」）、
`……` で区切ると間を取って2枚の字幕に、行末の `(間)` で長めの間。

## 解説の書き方

典型問題の解説は次の順で書きます。

1. `>[q]` 何を聞いている問題か、問題文のどこを見るか
2. `>[正解]` 正解とその根拠（スライド・図）
3. `>[他]` 他の選択肢がなぜ違うか（何と入れ替えられているか）
4. `>` 次に同じ形が出たときの考え方・覚えておくこと

`npm run build:narration` はスライド番号・マスク番号・図のキー・アニメのステップ・問題IDを検証し、
存在しないものを参照するとエラーで止まります。

## 黒板授業（`@bb`）― 板書が授業とともに積み上がる

`@bb` を使う講義では、1コマの授業に **1枚の黒板** があり、先生がチョークで書いたものがすべて残っていきます。
板書の各アクションは「一緒に話すセリフ」に結びつくので、黒板は授業時刻だけで決まります
（シーク・10秒戻る/進む・倍速・「完成した黒板」・クイズ解説の差し込み図・5分復習が同じデータから描かれます）。

黒板は 3200×1800 の座標で、上に **タイトル帯（T）**、その下に **左＝基本概念（L）・中央＝メカニズム（C）・右＝試験ポイント（R）**、
いちばん下に **まとめ帯（B）** があります。各パネルは書き位置（カーソル）を持ち、1行書くと下に進みます。

```
@bb [cam]                 黒板を映す（初回は黒板全体）。cam = L C R B T all LC CR または x,y,w
@cam L|C|R|B|all|follow   次のセリフからカメラを移動（follow = 書いている場所を自動で追う：既定）
@in L [x y]               パネルLに書く（x,y はパネル内の位置。省略するとLの続きから）
@at x y / @gap n / @over id   カーソルを移動（@over は消した場所に書き直すとき）

+ 文字                    1行書く。「+」の直後にフラグ：w y r b（チョークの色）# 見出し s 小さく 2 タイトル = 中央寄せ > 字下げ
+y# {dna} DNA             {id} を付けると、あとで囲む・消す・指すことができる
+ DNA → RNA               「→」はチョークで矢印を描く。[r:転写] で一部だけ色を変える
+↓ 転写 / +↓s 折りたたみ   前の行の下に矢印（ラベル付き、s は短い矢印）
+ln x,y x,y … >  +rc x,y,w,h  +el cx,cy,rx,ry  +arc cx,cy,r,度0,度1 >  +tx {id} x,y 文字
+sk helix | ladder ATGC | nucleotide | chromosome | gene 900 | mrna AUG GCU GUU UAG | nucleosome 4
+{ id … +}                グループ化（複数の線や文字を1つのアクションに）

!o id [色] / !oo id       丸で囲む / 2重丸（強調）。既定は赤チョーク
![] id / !u id / !uu id / !v id   四角で囲む / 下線 / 二重下線 / チェック
!x id,id                  消す（黒板消しでこすった跡がうっすら残る）
!p id,id                  次のセリフの間、先生がそこを指す（手と光）

> セリフ                  直前の板書アクションは、このセリフを話しながら書かれる
>~                        無言で書く間（板書だけ進む）
>! セリフ                 「重要ポイントだけ」再生モードに含める
@keys 見出し              授業の最後の「今日の重要ポイント」。項目の末尾に @id,id で黒板の該当箇所
@quiz g11b check ref=a,b  解説のときに、黒板の a・b の部分を差し込み図で表示
```

- 色の意味：**白＝基本、黄＝重要、赤＝最重要・試験頻出、青＝補足・関連**。色は乱用しない。
- セリフは板書が終わるまで次に進みません（書いている間は字幕を読む・考える時間になる）。
- 文字の幅はフォント（Klee One）の実測値で見積もり、**パネルからはみ出す行・既存の板書と重なる行はビルド時にエラー**になります。
  メッセージに従って `@gap`・`@in`・小さい文字（`+s`）・改行で直してください。
- 黒板を使う講義は `version` が 4 になり、古い収録音声とは自動的に切り離されます。
