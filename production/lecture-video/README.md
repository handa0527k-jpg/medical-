確認問題の選択肢の解説（A〜E）は映像では省き、考える問題（G-C対とA-T対）は本文として残しました。

医学図の正確さ（すべての強度で同一）は次のとおりです。

- ヌクレオチドのリン酸は糖の5'（環の外のCH₂）に、塩基は1'に付く。
- 五炭糖はハース式で、環は炭素4つと酸素1つ。β-D-リボースは1'のOHが上、2'と3'のOHが下、4'のCH₂OH（5'）が上。2-デオキシリボースは2'がH。
- プリンは6員環と5員環が縮合し、窒素は1・3・7・9位、糖は9位に付く。ピリミジンは6員環で、窒素は1・3位、糖は1位に付く。置換基の位置は塩基ごとに正しい（TとUの違いは5位のメチル基だけ）。
- ワトソン・クリック型塩基対：A N6–H…O4 T、A N1…H–N3 T（2本）／G O6…H–N4 C、G N1–H…N3 C、G N2–H…O2 C（3本）。糖の付く位置は両方とも同じ側で、どの対も1'炭素どうしの幅が同じ。
- 二重らせんは右巻きで、幅2 nm、1回転3.4 nm（10塩基対）。2本鎖は逆平行。
- 鎖の中の結合は3'炭素–O–P–O–次の5'炭素（ホスホジエステル結合）で、鎖は5'→3'に伸びる。
- cAMPは1つのリン酸が同じ糖の3'と5'をつなぐ環。dNTPはデオキシリボースにリン酸3つ。
- 痛風の場面は足だけを描き、顔は描かない。

音声は6分3秒で、Whisper（small）で聞き取った文字誤り率は10.3%です。第1講より高いのは、英字（DNA・NTP・cAMP など）と数字の読みが多いためです。
