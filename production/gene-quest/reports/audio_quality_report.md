# 音声品質レポート

**最初に明記すること**：この作品の音声は、人が耳で聴いて確認していない。制作環境（クラウド上のコンテナ）に再生装置がなく、
制作者（Claude）は音を聴けないためである。以下の判断はすべて、音声認識による書き起こし・客観指標・波形の測定にもとづく。
自動検査の結果は「品質の保証」ではない。公開前に、人が全編を通して聴くことを強く勧める（とくに医学用語の読みとイントネーション）。

## 1. 音声合成モデルの比較と選定

比較の詳細は `reports/audio_comparison.md`（数値は `audio_comparison.csv`、`audio_comparison_squim.csv`）、
比較音声は `audio/comparison/`。同じ8文（医学用語4文・会話4文）を各モデルで合成して比べた。

| 候補 | 結果 |
|---|---|
| Style-Bert-VITS2 2.5.0（JP-Extra） | 6モデルを比較。感情スタイル（Happy/Surprise/Sad など）があり、キャラクターの演じ分けに向く。医学用語文の CER 0.128〜0.212 |
| Kokoro-82M（kokoro-onnx） | 5音声を比較。医学用語文の CER が最も低い（jf_alpha 0.056）。感情スタイルはない |
| edge-tts | この環境のプロキシが WebSocket を通さず接続できなかった。比較に含めていない |

どちらが優れているかは前提にせず、役割ごとに選んだ。

| 役 | 選んだ声 | 理由 | 行数 |
|---|---|---|---|
| ナレーション | Kokoro jf_alpha | 説明文が中心で感情は不要。医学用語の書き起こし誤りが最も少ない | 29 |
| ヌク（案内役） | SBV2 jvnv-M2-jp | 会話文の CER が最も低い（0.025）。落ち着いた男性声。SQUIM MOS 推定 4.75 | 157 |
| アカリ（医学部生） | SBV2 jvnv-F2-jp | 感情スタイルで驚き・疑問を出せる。医学用語文の CER がSBV2の女性声で最も低い（0.130） | 44 |
| ポル（RNAポリメラーゼ） | SBV2 jvnv-M1-jp（高さ 0.94） | ヌクと聞き分けられる低めの男性声 | 6 |
| シグマ・ミーナ | SBV2 小春音アミ | 明るい声。アカリと別の声質 | 7 |
| スプラ・TFIID | SBV2 jvnv-F1-jp | 端役。アカリと別の声質 | 3 |

限界：モデル選定は8文での比較で、聴感による評価をしていない。SQUIM（参照なしの品質推定）の値はどの候補も MOS 推定 4.3〜4.8 で差が小さく、選定の決め手にはしていない。

## 2. 読み（発音）の管理

- 表示（字幕）と読み（音声合成への入力）を分けている。読みは `config/pronunciation_dictionary.yaml` で置き換え、原稿の `{say=}` で行ごとに上書きできる
- `build_script.py` は、読みに英字が残ると停止する（英字の用語を読み違えたまま合成しないため）
- 全246行を Whisper small で書き起こし、かな換算の誤り率（CER）を出した：`reports/pronunciation_check.md`（下の 5. に要約）

## 3. セリフ単位の処理（`scripts/process_audio.py`）

測定してから、必要な処理だけを行った。全246行、合計 1626.6 秒。

| 処理 | 条件 | 適用した行 |
|---|---|---|
| 前後の無音のトリム（−45 dBFS 未満、40 ms は残す） | 全行 | 246 |
| 低域カット（70 Hz） | 全行 | 246 |
| 明瞭度の補正（3.5 kHz +2 dB） | 2〜5 kHz 帯が 0.2〜1 kHz 帯より 12 dB 以上低い行 | 176 |
| 音量の正規化（−20 LUFS） | 全行 | 246 |
| コンプレッサー（2:1） | ピークと平均の差が 17 dB を超える行 | 147 |
| ピーク制限（−1.5 dBFS） | 正規化後に超えた行 | 1（SC0907-06） |
| ノイズ除去 | ノイズフロア −60 dBFS 超の行を記録 | 7行が該当したが**除去はしていない**（下記） |

測定値：

- 音割れ（最大値に3サンプル以上連続して張り付く箇所）：0 行
- ノイズフロア（最も静かな 20 ms の RMS）：中央値 −71.8 dBFS、最大 −50.6 dBFS。2行は文中に間がなく測定不可
- 正規化前のラウドネス：−22.2〜−10.8 LUFS（行による差が最大 11.4 dB あったため正規化した）
- ノイズの多い7行（SC0104-02, SC0202-07, SC0205-03, SC0402-08, SC0405-04, SC0604-04, SC0907-07）は、最大でも −50.6 dBFS で、
  BGM の下ではほぼ聞こえない水準。合成音声にノイズ除去をかけると子音がにごる恐れがあるため、DeepFilterNet などは使わなかった。
  人が聴いて気になる場合だけ、その行を作り直す（`generate_audio.py --line <ID> --force`）のがよい

段階別の比較用ファイル：`audio/processed/stages/<行ID>__1_raw.wav`（合成そのまま）→ `__2_eq.wav` → `__3_norm.wav` → `__4_comp.wav` → `__5_final.wav`。
各話者の最初の数行（21行×5段階＝105ファイル）を保存した（容量の都合で git には入れていない。`process_audio.py --stages` で再生成）。

## 5. 発音の確認（Whisper small）

全246行を Whisper small で書き起こし、台本の読みとかな換算で比べた（詳細と1行ごとの判断は `reports/pronunciation_check.md`、数値は `audio/pronunciation_check/report.csv`）。

| 話者 | 行数 | 平均 CER |
|---|---|---|
| ナレーション（Kokoro） | 29 | 0.059 |
| アカリ（SBV2 F2） | 44 | 0.107 |
| ヌク（SBV2 M2） | 157 | 0.083 |
| ポル | 6 | 0.089 |
| シグマ・ミーナ | 7 | 0.013〜0.023 |
| スプラ・TFIID | 3 | 0.056〜0.108 |
| 全体 | 246 | 平均 0.083、中央値 0.059 |

CER が 0.15 を超えた43行を1行ずつ見た。21行は漢字・英字への変換違いだけ、1行は叫び声、21行を「要聴取」とした。
いちばん大きな懸念は、**アカリの声で、アルファベットの「ティー」（T）が「キー」と書き起こされること**（8行）。
読みの書き方を変える試作でも安定して改善しなかったので、作り直しはしていない。公開前に人が聴いて確かめ、
聞き取りにくければ、その行だけ声や言い回しを変えて `generate_audio.py --line <ID> --force` で作り直す。

## 6. まとめ（できていること・できていないこと）

- できている：すべてのセリフの合成・測定・仕上げ、比較用の段階別ファイル、ミックスの数値目標（−16 LUFS、ピーク −1.5 dBFS 以下、音割れなし）、書き起こしによる読みの確認
- できていない：**人の耳による試聴**（全編・抜き取りとも）。そのため、声の自然さ・感情表現・BGM と効果音のバランスの聴感、アカリの「ティー」の聞こえ方は未確認
