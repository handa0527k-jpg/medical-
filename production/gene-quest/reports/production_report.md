## 2. 制作環境と制作の流れ

クラウド上の Linux コンテナ（4コア CPU、メモリ 15 GB、GPU なし）。ユーザーの PC や Kaggle ではない。

1. 環境調査：Python 3.13、FFmpeg 6.1.1（libx264・libass あり）、GPU なし、ネットワークはプロキシ経由（WebSocket 不可）を確認
2. PDF 解析：全73ページをテキストと画像で確認 → `research/`
3. 脚本：`script/source_script.md`（1ファイルに、シーンの設定・セリフ・感情・読みの上書き・補足の印を書く）。初稿は約44分になったため、内容を削らずに言い回しを短くした第2稿で約30分に収めた
4. 音声合成の比較 → 役ごとに選定（`reports/audio_quality_report.md`）
5. 読み方辞書・セリフ単位の音声合成（再開可能、変わった行だけ作り直し）・測定にもとづく仕上げ
6. 音声の長さからタイムラインを作り、字幕・効果音・BGM ミックスを作成
7. 30秒の試作（`video/previews/prototype_30s.mp4`）で、描画・口の動き・字幕・ミックスの流れを確認してから全編を制作
8. 52シーンの描画（skia によるベクター描画をフレームごとに FFmpeg へ渡す。シーンごとに4並列）
9. 統合・技術検証・全編から抜き出したフレームによる目視確認と修正

処理時間の実測（この環境）：音声合成 246行で約9分（合成時間の合計 520 秒、音声 1631 秒分）、全シーンの描画は約16分（4並列）、
完成版の書き出し（字幕焼き込み・再エンコード）約15分、検証（全フレームのデコードと黒画面検出）約3分。

## 3. ツールの選定

| 用途 | 使ったもの | 理由 |
|---|---|---|
| 映像 | skia-python（2D ベクター描画）＋ 自前の透視投影（3D の二重らせん） | GPU なしでも 1080p を実用的な速度で描ける。分子の形・ラベル・矢印をコードで正確に制御でき、修正したシーンだけ作り直せる |
| 音声合成 | Style-Bert-VITS2 2.5.0（キャラクター）、Kokoro-82M（ナレーション） | 比較の結果による（音声品質レポート） |
| 字幕 | ASS（libass で焼き込み）＋ SRT（字幕トラック） | 話者名の色分けと半透明の帯。焼き込みなしでも字幕トラックで表示できる |
| 統合 | FFmpeg（引数をリストで渡し、空白・日本語のパスでも動く） | |
| 評価 | faster-whisper small、torchaudio SQUIM、pyloudnorm、pyworld | |

使わなかったもの：

| ツール | 理由 |
|---|---|
| edge-tts | この環境のプロキシが WebSocket を通さず接続できなかった。回避する設定変更は行っていない |
| Blender | GPU のない環境で30分の3Dレンダリングは非現実的。3D は二重らせんに限り自前の投影で描いた |
| OpenToonz／Krita | 手描きの作画工程が必要で、自動化と修正の再現性に向かない |
| DeepFilterNet | 合成音声のノイズフロアが中央値 −71.8 dBFS で、ノイズ除去が不要だった |
| 画像生成 AI | キャラクターの一貫性を保証できず、医学的な図の正確さも制御できない |

制作指示で第一候補とされた `pmplabs/Style-Bert-VITS2` はこの環境から確認できなかったため、PyPI の `style-bert-vits2` が示す公式リポジトリ（litagin02）を使った。

## 5. 技術検証で見つけて直したこと

- **完成版が10.45秒短かった**：書き出しの `-shortest` 指定が、字幕トラックの最後の字幕（1822.4 秒）で動画を終わらせていた。
  映像と音声はどちらも 1832.87 秒で一致していた。`-shortest` を外し、代わりに統合前に映像と音声の長さを照合して、ずれていれば止めるようにした
- 冒頭 0〜1.43 秒の黒画面は、プロローグの暗転からのフェードイン（演出）

## 6. 目視確認で見つけて直したこと（完成版のフレームから）

- 長い字幕の半透明の帯が、画面左下のアカリの顔にかかっていた → 帯の左端が顔にかからない位置まで、長い字幕だけ右へずらした（短い字幕は中央のまま）
- SC0505「★ 調節はここ」が原核生物の枠の文字と重なっていた → 位置を変更
- SC0603 切断後に離れていく配列（GU・3'）が薄く残り、「Aを250個まで付加」の文字と重なっていた → 完全に消えるようにした
- SC0802「フィードバックループ → 約24時間のリズム」がヌクと重なっていた → 位置を変更

（これ以前にも、シーンごとの静止画の確認で、ラベルの重なり、ポリメラーゼの溝と DNA の位置、CTD の向き、エンハンサーのループの向きなど多数を直した）

## 7. 正直に記すこと（未確認・限界）

- **全編を人の目と耳で通して視聴していない**。制作者（Claude）は動画を再生して視聴できず、音も聴けない。確認は、静止画・抜き出したフレーム・書き起こし・客観指標・技術検証による。公開前に、人が全編を通して視聴・試聴することを強く勧める
- 音声の自然さ・感情表現・BGM と効果音のバランスは、聴感では確認していない（数値は音声品質レポート）
- アカリの声で、アルファベットの「ティー」が「キー」と聞こえる可能性がある（書き起こしの傾向。8行）
- 医学的内容は専門家の監修を受けていない
- Kaggle Notebook は Kaggle 上では実行していない（ローカルでの実行結果は README と下の 8.）
- キャラクターは胸像と浮遊キャラクターの2D描画で、口は音量に合わせて開閉する（母音ごとの口形はない）
