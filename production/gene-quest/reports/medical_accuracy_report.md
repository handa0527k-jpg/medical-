# 医学的正確性レポート

**最初に明記すること**：この確認は、制作者（Claude）が講義資料と照合して行ったもので、医師・研究者・資料の作成者による監修は受けていない。
教育に使う前に、講義担当者など専門家の確認を受けることを強く勧める。

## 1. 根拠と方法

- 一次情報：講義資料「転写（機構と疾患）」（2026年度 遺伝医学、2026.09.28、熊本大学大学院生命科学研究部 分子遺伝学）。全73ページ（`source/lecture_materials/`）
- 全ページをテキスト（`research/pdf_text_raw.txt`）と画像の両方で読んだ。図だけのページ（テキストが取れないページ）は画像で内容を確認した
- 内容の整理：`research/lecture_summary.md`（章ごとの要点と根拠ページ、要確認事項 Q1〜Q10）
- シーンごとの照合：`research/accuracy_checklist.md`。57シーンそれぞれについて、台本の文と、描画した図（静止画を書き出して目で確認）を、該当ページの本文・図と照合した
- ページ番号：PDF のページ番号（1始まり）。画面右上に「講義資料 p.○」として表示し、字幕・台本（`script/master_script.md`）にも記録した
- ページとシーンの対応：`research/page_mapping.csv`（73ページ中62ページを使用。使わなかった11ページの理由は確認表の「使わなかったページ」）

## 2. 講義資料にない知識（補足）の扱い

資料にない一般知識は最小限にし、台本で `{note=補足}` を付け、画面に「補足（講義資料外の一般知識）」と表示した。該当は4行のみ。

| 行 | 内容 | 補足にした理由 |
|---|---|---|
| SC0301 | 細菌には核がなく、DNA は細胞質にある | 資料は原核・真核の比較を前提にしており、核がないことを明記していない |
| SC0306 | ラクトースから生じる物質がリプレッサーを外す | 資料（p.24）はリプレッサーがオペレーターに結合することまでを示し、ラクトースがあるときに外れる仕組みは書いていない |
| SC0604 | 切る位置が1塩基ずれると読み枠がずれ、別のアミノ酸が並ぶ（境目の目印が必要な理由） | 「3塩基で1アミノ酸」は p.71 にあるが、読み枠のずれ（フレームシフト）は資料に書かれていない |
| SC0503 | エピジェネティック制御の言い換え | 語は資料の重要語句（p.2）にあるが定義の記載がないため、塩基配列を変えずに発現を調節することを補った |

## 2a. 必然性の問い（v3）の根拠

v3 では、仕組みごとに「なぜ、そうでなければならないのか」を問い、答えを講義資料の記載から組み立てた。
資料にない理由は使わないか、「補足」と表示した。資料の記載からの推論（論理的な帰結）にとどめたものは、その旨を記す。

| シーン | 問い | 答えの根拠 |
|---|---|---|
| SC0104 | なぜ DNA を直接使わず、RNA に写すのか | mRNA は核で作られ、細胞質へ運ばれてから翻訳に使われる（p.4, 71） |
| SC0202 | なぜ相補的に作られるのか | 相補的塩基対（p.7）からの論理的帰結（相手が一つに決まる） |
| SC0203 | なぜ 5'→3' にしか伸びないのか | 伸びている RNA の 3'OH に新しいヌクレオチドの 5' 三リン酸がつながる（p.8） |
| SC0204 | なぜプロモーターという目印が要るのか | プロモーターが開始点と鋳型鎖を決める（p.71） |
| SC0304 | なぜ転写を調節するのか | 調節的発現遺伝子は必要に応じて変化する（p.26）。ラクトースの例（p.23, 24） |
| SC0305 | なぜオペロンにまとめるのか | 同じ転写因子の調節を受け、連携して働く酵素の遺伝子の集まり（p.25） |

## 4. 制作指示 2-3 の確認項目

`research/accuracy_checklist.md` の「確認項目」に結果を記した。要点：

- 映像に出る塩基配列はすべて相補性を検算した（SC0202 の 3'-TACTTTACGAT-5' → 5'-AUGAAAUGCUA-3'、SC0203、SC0205、SC0302）
- RNA の合成方向は常に 5'→3'、鋳型鎖は 3'→5' に読む。転写の図は p.19 の向き
- 原核（σ因子・−10/−35・オペロン）と真核（TATA・基本転写因子・スプライシング）を章で分け、比較の場面（SC0404、SC0505）と第2問で区別を確認
- スプライシングの順序は p.51–52 の5段階どおり
- 疾患との関係は資料の記載の範囲にとどめ、「関連」と「原因」を区別した

## 5. 限界と残る課題

- 専門家の監修を受けていない（上記）
- 確認は、シーンごとの静止画と、全編から約15秒ごとに抜き出した121枚のフレームによる。全編を通して動画として人が視聴していない
- 分子の形（ポリメラーゼ、スプライソソームなど）はキャラクター化した模式図で、実際の立体構造ではない（画面と台本で「模式」と明示した箇所あり）
- 資料の数値（例：p.55 の内訳）や記載をそのまま使った箇所は、資料自体の誤りがあればそれを引き継ぐ
- 音声の読み違いの可能性（`reports/pronunciation_check.md` の「要聴取」）。字幕は正式な表記で表示している
