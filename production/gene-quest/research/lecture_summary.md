## D. 転写調節

| 項目 | 資料の記載 | ページ |
|---|---|---|
| エンハンサー等 | エンハンサーは転写効率を増強、逆はサイレンサー。転写活性化因子がDNAの特異的配列に結合しPolを開始部位へ引きつける。介在因子（mediator）は活性化因子とPol II・基本因子群の結合に機能。クロマチン再構成複合体やヒストン修飾酵素などのクロマチン修飾酵素が必要 | p.34 |
| 調節配列 | 遺伝子から数百〜数千bp離れた上流（または下流）のエンハンサー、サイレンサー、その他の応答配列が調節的発現に関与。遠位調節要素／近位調節要素（=上流プロモーター要素、GC/CAAT）／プロモーター（TATA, Inr）。基礎的発現・調節的発現 | p.35, 38 |
| ホルモン・発生・分化 | (b)ホルモンや調節分子が発現を調節（受容体からの信号→ホルモン応答性遺伝子）(c)β-グロビン遺伝子は発生段階（胚・胎児・成体）で制御 (d)分化した細胞は異なる遺伝子を発現（オン/オフのパターンの違い）。甲状腺刺激ホルモン（下垂体前葉）、甲状腺ホルモン（甲状腺）の語 | p.36 |
| コミットメント | 細胞のコミットメントと転写因子：正常分化（lineage A）と、分化ブロック＋他系統への分化＋自己複製能 | p.37 |

## E. RNAプロセシング

| 項目 | 資料の記載 | ページ |
|---|---|---|
| 過程 | 1）Pol IIによるmRNA前駆体の合成 2）5'キャップの付加 3）ポリAの付加 4）スプライシングによるイントロンの除去とエクソンの結合。完成したmRNAは核から細胞質に出た後にリボソームで翻訳に使われる。キャッピング酵素、ポリ(A)ポリメラーゼ、スプライセオソーム、hnRNA（ヘテロ核RNA） | p.46 |
| 5'キャップ | 5'末端（ppp）へのGの付加 → Gが7位の窒素の部分でメチル化（m7G） | p.47 |
| ポリA | ポリアデニル化シグナル AAUAAA と GUに富む配列。エンドヌクレアーゼが2つのシグナルの間を切断（3'側がやや短くなる）。ポリ(A)ポリメラーゼが250個までのAを付加（20〜250個） | p.47 |
| 安定性 | 5'キャップやポリAはmRNAを細胞内のエキソヌクレアーゼの攻撃から守る。長時間必要なタンパク質のmRNAは安定性が高く、短時間のみ必要なものは低い | p.47 |
| スプライシング | 複数のエクソンを持つ不連続遺伝子の転写産物からイントロンを除去する過程。GT-AG規則（5'スプライス部位 …GT…、3'スプライス部位 …AG…）。ヒト遺伝子のイントロン表（インスリン 1.4 kb・2個・67%、ジストロフィン 2400 kb・78個・99% など） | p.48 |
| snRNA/snRNP | イントロンはGT（RNAではGU）で始まりAGで終わる。ブランチ部位のA。snRNA（非翻訳RNA）とタンパク質の複合体（スプライセオソーム）が切断点近傍と結合して2つの切断点を引き寄せる。snRNAは普段タンパク質と結合してsnRNPとして働く。U1, U2, U4, U5, U6 | p.50, 57 |
| 手順 | 1）U1 snRNPがイントロン5'末端のGUに結合（U1 snRNAが塩基対）2）U2AFがブランチ部位の下流に、U2 snRNPがブランチ部位に結合 3）U5, U4, U6 snRNPが集まり本格的に開始 4）U1が放出されGUが開放、U5・U6が近づく。次にU4が放出、U6がU2に結合 5）U6がGUとも塩基対、U2/U6がGUの5'側で切断し、GのG塩基をブランチ部位のA塩基と結合させ投げ縄構造（ラリアット）を形成。U5が切り離されたエクソンとイントロン3'末端のAGに結合し、AGの3'側で切断された後も2つのエクソンを離れないようにしている | p.51, 52 |
| 選択的スプライシング | E1〜E4 の前駆体から、Aの場合 E1-E3-E4、Bの場合 E1-E2-E4（ある部分全体が1つのイントロンとしても機能しうる）。例：グルコキナーゼ遺伝子の選択的プロモーター利用（肝臓は1L、膵B細胞/下垂体は1B）。異なるプロモーター周辺配列で組織特異的な転写調節 | p.49 |
| ヒト遺伝子の構造 | プロモーター、5'UTR、開始コドン(ATG)、エクソン、イントロン、終止コドン(TGA)、3'UTR、ポリアデニル化シグナル。DNAはAGCT、RNAはUCGA。転写→スプライシング→翻訳（AUG〜UGA） | p.53, 61 |
| まとめ | 1種類のpre mRNAからスプライシングで複数のmRNAが作られ、多様なタンパク質が遺伝子の数よりも多く作られる。真核のmRNAはpre mRNAとして転写され、核内でキャッピング、ポリA付加、スプライシングを経て完成し細胞質へ。タンパク質の情報単位はDNA上の3つの塩基配列で1つのアミノ酸に対応 | p.71 |
