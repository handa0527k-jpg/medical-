# キャラクター設定資料

全キャラクターはオリジナル。画像生成AIは使わず、`scripts/gqlib/chars.py`（アカリ・ヌク）と `scripts/gqlib/mol.py`・`scenes/ch7.py`（分子キャラクター）の**同じ描画関数**で全シーンを描くため、外見・配色はシーンが変わっても一致する。
設定画（本編と同じ関数で書き出したもの）：`characters/references/akari_expressions.png`、`nuku_expressions.png`、`molecule_characters.png`（`python scripts/make_character_sheet.py` で再生成）。

## アカリ（主人公）

| 項目 | 設定 |
|---|---|
| 役割 | 視聴者の代わりに疑問を持つ医学部1年生。最初から知っているわけではなく、質問しながら理解していく |
| 性格 | 好奇心旺盛、率直に質問する。たとえを自分の言葉で言い直す（例「写すのが転写で、置き換えるのが翻訳か」） |
| 外見（正面） | 濃紺のボブヘア（天使の輪のつや）、前髪は房状、左側にDNAのらせん形ヘアクリップ（紫と青緑の粒）。琥珀色の大きな目、白衣、青緑のシャツ、コーラルのリボン、胸ポケットにDNA柄の名札、青いペン |
| 側面 | 本作は胸像の正面〜わずかな傾き（±6°）で演技する。横向きは使わない（左右反転のみ可） |
| 色 | 髪 #2A2145／つや #5B4A8F、肌 #FFE3D2、虹彩 #7A3B12→#FFB45C、白衣 #F7F8FF、シャツ #2BB5A3、リボン #FF6F8A、字幕の名前色 #FFB8C8 |
| 表情 | ふつう・うれしい・おどろき・考える・こまる・かなしい・こわい・決意（`EXPRESSIONS`）。セリフの感情スタイルから自動で選び、話し終えて約2.5秒で戻る |
| 基本ポーズ | 画面左下の胸像（縮尺0.4〜0.7）。研究室の場面のみ大きく（0.9〜0.95） |
| 演技 | まばたき（3〜4秒ごと）、呼吸、話すときに頭がわずかに揺れ、口は音声の音量包絡で開閉 |
| 声 | Style-Bert-VITS2 jvnv-F2-jp（感情スタイル：Neutral／Happy／Surprise／Fear／Sad） |
| 使ってよい表現 | 驚き、疑問、納得、発見、決意、明るい冗談 |
| 使ってはいけない表現 | 専門知識の先回り（説明役の内容を先に言う）、患者や疾患をからかう表現、過度なデフォルメ（目の形が崩れる表情） |

## ヌク（案内役）

| 項目 | 設定 |
|---|---|
| 役割 | 細胞の世界の案内役。たとえ → 正式な用語 → 実際の分子機構の順に説明し、資料外の知識は「補足」と言う |
| 性格 | 親しみやすく落ち着いている。ほめて進める |
| 外見 | ミントグリーンの球体（直径約190px）、核膜のリングを思わせる軌道リング（紫・青緑・黄のビーズ＝DNA・RNA・塩基）、頭に紫（DNA）と青緑（RNA）の双葉、小さな浮く手 |
| 色 | 体 #D8FFF3→#6FF0C8→#1FB58C、目 #0E3B31、字幕の名前色 #9FF5DA |
| 表情 | ふつう・うれしい（∩目）・おどろき・考える・こまる・わくわく |
| 演技 | 上下にふわふわ浮く、リングが回る、話すと体がわずかに伸び縮みする、指したい方向に手を伸ばせる |
| 声 | Style-Bert-VITS2 jvnv-M2-jp（比較で会話文の書き起こし誤り率が最も低かった声） |
| 使ってはいけない表現 | たとえだけで説明を終える、資料にない因果関係を断定する |

## 分子キャラクター

性格は分子の機能と矛盾しないようにした。形と色は講義資料の模式図に合わせ、顔は会話する場面だけに付ける。

| キャラクター | 分子 | 外見の根拠 | 性格（機能との対応） | 声 |
|---|---|---|---|---|
| ポル | RNAポリメラーゼ（原核のコア酵素・真核のPol II） | p.5, 13–17, 30 の水色のクランプ型。Pol II は CTD（尾）を持つ | 落ち着いた職人。「職人というのはたとえ」と自分で断る（＝RNAを合成する酵素） | jvnv-M1-jp（低め pitch 0.94） |
| シグマ | σ因子 | p.13 の赤橙のかぎ形 | 目印（−35/−10）を見つけるのが得意、開始後は離れる（p.16） | 小春音アミ |
| TFIID | TFIID（TBP＋TAF） | p.30 の緑のカプセル、下の濃い緑が TBP | 最初に来て TATA を見分ける | jvnv-F1-jp（低め） |
| スプラ | スプライソソーム | p.50 の snRNP の色（U1 緑・U2 黄・U4 橙・U5 桃紫・U6 水色）を周りに配置 | 手順どおりに切ってつなぐ工房 | jvnv-F1-jp（高め） |
| ミーナ | 成熟 miRNA | 約22塩基の短い青緑のRNA | mRNA に結合して翻訳を抑える側（mRNA とは役割が違う） | 小春音アミ（高め） |

ナレーションは Kokoro（jf_alpha）。実在の声優の声は使っていない（各モデルの利用条件は README の「ライセンス」）。
