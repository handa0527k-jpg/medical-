## 投稿の手順（YouTube Studio）

1. YouTube Studio →「作成」→「動画をアップロード」で `rojiura_no_genome.mp4` を選ぶ。
2. **タイトル**・**説明**：`title.txt` と `description.txt` を貼り付ける。説明の「0:00 …」の行から**チャプター**が自動で作られる（11章）。
3. **サムネイル**：`thumbnail.jpg` をアップロード（電話番号の確認が済んだアカウントで使える）。
4. **視聴者**：「いいえ、子ども向けではありません」。
5. **詳細**：タグ（`tags.txt`）、動画の言語「日本語」、カテゴリ「教育」。
6. **改変または合成されたコンテンツ**：実在の人物や出来事を本物らしく見せる内容ではないアニメーションなので、通常は「いいえ」でよい。絵と声が AI で作られていることは説明文に書いてある。
7. **字幕**：「字幕」→ 言語「日本語」→「ファイルをアップロード」→「タイミングあり」で `rojiura_no_genome_ja.srt`。画面に字幕が焼き込まれているので、主に他言語の自動翻訳と検索のため。
8. **終了画面**：最後の約16秒がクレジットなので、ここに「次の動画」「チャンネル登録」を置ける。
9. 公開設定は、まず「限定公開」で確認してから「公開」にするのがおすすめ。

## 公開する前に確かめること

- **講義資料**：台詞と図の内容は講義資料「遺伝子工学」（2026）に沿っていますが、資料の図そのものは使っていません（すべて描き起こし）。資料が大学・講師のものなら、一般公開してよいか念のため確認してください。
- **音声合成**：声は edge-tts 経由の Microsoft ニューラル音声です。この経路は Microsoft の公式な商用ライセンスではありません。収益化する場合は、Azure の音声サービス（有料・商用可）で作り直すか、ご自身の声に差し替えてください（`tools/tts.py` の `synth()` を差し替えれば、ほかは同じ手順で作り直せます）。
- **画像生成モデル**：Nova Anime XL（OpenRAIL++）。生成物の利用に制限はありませんが、モデルのライセンス条件（違法・有害な用途の禁止など）に従います。
- **フォント**：しっぽり明朝・Zen 角ゴシック New（SIL OFL）。動画への使用に制限はありません。
- **音楽・効果音**：すべて自作の合成なので、著作権の申し立て（Content ID）の心配はありません。
