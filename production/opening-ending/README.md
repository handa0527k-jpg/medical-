# ストーリーアニメの OP / ED

全ストーリーアニメに共通のオープニングとエンディング。機序アニメには付けていない。
曲に合わせて切るミュージックビデオで、人物は動きの自然さを優先して単色シルエットにしている。
コードは `src/engine/story/mv/`（`op.ts` `ed.ts` `common.ts` `music.json`）にある。

## 曲（魔王魂・フリー音源）

| | 曲 | 版 | 長さ | 曲の終わり | 1小節 |
|---|---|---|---|---|---|
| OP | 「シャイニングスター」 https://maou.audio/14_shining_star/ | ショート | 88.6 s | 87.0 s | 約1.53 s（約158 BPM） |
| ED | 「The milky way」 https://maou.audio/29_the_milky_way/ | ショート | 112.6 s | 111.07 s | 約2.28 s（約105 BPM） |

- **曲を途中で切らない。** どちらもショート版を最後まで流す。曲の終わりに合わせて映像を黒へ落とし、
  そのあと 1 秒ほど音をフェードアウトさせるだけ（`ffmpeg -af afade=t=out`、128 kbps）。
  出力先は `public/music/op-shining-star.mp3` と `public/music/ed-the-milky-way.mp3`。
- **利用規約。** https://maou.audio/rule/ を確認済み。商用・非商用ともに無料で使え、編集もアプリへの組み込みもできる。
  クレジットは「音楽：魔王魂」とする。ED のスタッフロールとストーリーページの注記に入れている。
  曲単体での再配布、AI の学習、ストリーミング配信、NFT 化は禁止されている。
- **入手した原曲は Git に入れない。** `audio/` に置き、`.gitignore` で除外している。
  ダウンロードするときは、曲ページを Referer として送る必要がある（送らないと 403 になる）。

## 曲の解析（`music.json`）

librosa 0.11 で解析した。

- **小節線（`bars`）。** 拍を推定し、打楽器成分の自己相関から 1 小節の長さを決めた。
  テンポの倍・半分の取り違え（161 と 108、105 と 70）はこの方法で解消した。
- **強拍（`hits`）。** 打楽器成分のオンセットのうち強いもの。`[時刻, 強さ]` で持つ。
- **セクション（`sec`）。** 音色の変化点を出し、耳で確かめて決めた。
  - OP：intro 0.8 / verse 9.94 / pre 22.09 / chorus 35.75 / climax 63.09 / outro 75.24 / end 87.0
  - ED：intro 2.36 / verse 11.51 / break 48.08 / chorus 54.93 / climax 84.65 / outro 100.65 / end 111.07

映像側の決まりごと：

- セクションの時刻は、いちばん近い小節線に寄せて使う（`sections()`）。
- 区間を何ショットかに割るときは、境目も小節線にそろえる（`shot()`）。
- タイトルが出る瞬間、ジャンプの頂点、ロゴの再登場は、いちばん近い強拍に合わせる（`snap()`）。

## 構成

**OP（主人公がたどる物語のあらすじ）**

1. **イントロ。** 夜明けの丘に主人公が立ち、クレジットが出る。キャッチコピーが一文字ずつ現れ、verse の 2 小節前の強拍でタイトルが入る。
2. **A メロ。** 登場人物を 1 小節に 1 人ずつ紹介する。背景はその人物の色で、名前と役どころを出す。
3. **B メロ。** 本編の各場面を静止画にして額縁に入れ、場面番号・題・あらすじを見せる。
4. **サビ。**
   1. 主人公が走り、空を場面の題が流れていく。
   2. 本編の静止画を半小節ごとに切り替えるモンタージュ。
   3. 全員がこちらへ歩いてくる。
5. **クライマックス。** 2 小節目の強拍で主人公の跳躍が頂点に達し、そこで一瞬止まる。そのあと学習キーワードが周りを回る。
6. **アウトロ。** 全員が並んで手を振り、強拍でタイトルが再び出る。

**ED（学習のまとめ）**

- 夜空から夜明けへ移る丘を、主人公がゆっくり歩く。
- verse から climax までは、学習ポイント表の 1 行を 1 枚のカードにして、小節線で切り替える。
- climax からスタッフロールを流し、アウトロで主人公が立ち止まって「おわり」。

## 人物の動き

人物はすべて CMU Graphics Lab Motion Capture Database の実測モーションで動かしている。
既存のクリップ（walk / walk_casual / stand / stand2 / wave / explain / laugh / stretch）に、今回次の 2 つを足した。

- `run`：09_01 の走り。0〜1.2 s を使い、`loopRange` で 1 周期をループさせる。
- `jump`：16_01 の両足ジャンプ。0〜2.6 s を使う。
  骨盤の高さを測ると頂点は 1.25 s（+0.27 m）なので、その時刻を強拍に合わせている。

クリップは `scripts/film/make_clips.py` で生成する。生のデータは `.cache/mocap/` にあり、Git には入れていない。
人物は顔を描かず、関節をつなぐ単色シルエットにしている。
影は床（y = 0）に投影するので、跳ぶと影が地面に残ったまま小さくなる。

## 確認方法

```
npx vite --port 5199
node scripts/story-frames.mjs <course> <outdir> --mv op --at 2,8,12,25,40,52,60,66,72,85 --sheet
node scripts/story-frames.mjs <course> <outdir> --mv ed --at 8,20,60,90,104 --sheet
```

アプリの URL に `?op=秒` または `?ed=秒` を付けると、その位置から開く。

再生時の動き：

- 最初から再生すると OP が流れ、画面右上に「OPをスキップ」が出る。
- 本編が終わると ED に進む。ED が終わるか「EDをスキップ」を押すと、開始画面に戻る。
- 曲の音量は BGM の設定に従う。本編を倍速にしても、曲は常に 1 倍速で流れる。
