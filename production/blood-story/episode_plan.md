# BLOOD STORY ― 体内を駆ける細胞たち ― シリーズ構成（第1期・全4話）

講義資料「血液」（スライド2–65）を、4話の連続ストーリーで一通り学べるように割り振った。
各話 約4分50秒〜5分、セリフ37〜41行。数値はすべて資料の値。資料にない内容は各台本の末尾で「補足」と明記している。

### キャラクターの変化
- **シロウ**：第2話で一人では勝てないことを知る（#35）。第3話では、骨髄芽球から杆状核球へ育った子ども時代が明かされる。
- **ゴウ**：第2話では力を使うことを止められ、すねる（ヒスタミンはアレルギーにもつながる）。第4話ではいちばん見つけにくい細胞として、最後の主役になる。
- **ソウ**：第2話で単球からマクロファージになる（変身）。第3・4話では、仲間を導く先生役になる。
- **アカネ**：第3話で「流れの中で止まることも守ること」だと知る。第4話では、うつむくゴウを光の中へ引っぱり出す。
- **新キャラ**：ペタ（血小板）は第3話から登場し、第4話ではカメオで出る。キョウコ（巨核球）は第3話だけ。ミナトは第4話で声だけ出る。

## 3. 新しい映像素材（話数ごと）

既存の部品（`BS.world`・`BS.chars`・`BS.diag` の赤血球図と白血球図）は、そのまま使えるものは使う。下は**新しく必要なもの**だけ。
図の名前は `BS.diag.<name>(ctx,{x,y,scale,p,t})` の形を想定した案。

### 第2話
**模式図（新規）**
- `wbcClassify`：白血球の数（5,000〜9,000/mm³）と、核の形×顆粒の染色性の2軸で分類する図。顆粒球と無顆粒球の2グループに分かれる（スライド13）
- `neutrophilDetail`：好中球の拡大図。3〜5分葉核、約12 µm（「実際は約20%小さい」の注記つき）、特殊顆粒（0.2〜0.4 µm、淡いピンク）とアズール顆粒（0.5〜0.6 µm、青紫）、MPOからHOClが出る演出（スライド15）。既存の `neutrophilCard` を広げてもよい
- `receptorsOpsonin`：Toll様受容体、Fc受容体、C3受容体の3つの受容体と、細菌に抗体（Y字）と補体C3bが貼りつくオプソニン作用の図（スライド16・17）
- `phagolysosome`：既存の `phagocytosis` に、食胞へアズール顆粒と特殊顆粒が融合する段階を足した版（スライド16）
- `eosinophilCard`：二分葉核、0.5〜0.7 µmの顆粒、電顕で見える杆状結晶の芯、好酸球ペルオキシダーゼとMBPのアイコン（スライド18）
- `basophilHistamine`：IgEがFc受容体に結合 → 顆粒の中身を放出 → ヒスタミンが平滑筋を収縮させ、血管を広げ、透過性を上げる。3つの作用をアイコンで並べ、ぜんそくの気道も描く（スライド19）
- `antigenPresentation`：マクロファージがMHCの台に抗原のかけらをのせて見せ、T細胞が近づく。IL-1とTNF-αは光の粒で表す（スライド21）
- `lymphocyteCard`：8〜9 µm、T 60〜80%・B 20〜30%、TCRと表面免疫グロブリン（スライド22）
- `tbChart`：CD4ヘルパーT → サイトカイン → B細胞 → 形質細胞 → 抗体（IgM・IgG・IgA・IgE）。CD8キラーT → 感染細胞を破壊（スライド17・23）
- `nkAttack`：NK細胞のパーフォリンが膜に輪状の穴をあけ、グランザイムが入り、アポトーシスに至る（スライド24・25）

**背景**
- 体の外から見た指先の傷（シンプルな線画で、写実にしない）
- 細静脈の壁を横から見た図。好中球が内皮のすき間をくぐる
- 組織の戦場（血管外の結合組織。線維が走り、細菌が増える）
- 血管の裂け目（引きのカット。第3話のアバンでも使う）

**キャラのポーズ・差分**
- シロウ：`grab_miss`（つかみ損ねる）、`transmigrate`（壁をすり抜ける。squash を流用）、膝をつく疲労ポーズ
- ユズ：腕に MBP の光をまとう
- ゴウ：拳を鳴らすポーズ、制止されて腕を下ろすポーズ
- リン：抗体（Y字）を投げて目印をつけるポーズ
- ソウ：変身シーンと、**マクロファージ形態**（下の新キャラ欄）

**モブ**

- 様子のおかしい細胞（ウイルス感染細胞を記号的に描く）

### 第3話
**模式図（新規）**
- `plateletAnatomy`：2〜4 µmの円盤。硝子部と顆粒部、周縁の微小管束、開放小管系、α・δ・λ顆粒、暗調小管系（スライド26）。断面図と、赤血球と大きさを比べる図の2つ
- `plateletGranules`：各顆粒の中身のアイコン。α＝凝固因子・フィブリノゲン・PDGF、δ＝セロトニン・ADP、λ＝加水分解酵素（スライド26）
- `adhesionRelease`：内皮がはがれてコラーゲンが露出 → vWFが橋渡し → 開放小管系からCa²⁺ → 顆粒の中身を放出（スライド28）
- `aggregation`：血小板が球状に形を変えて偽足を出し、重なって傷口をふさぐ。「止血の5つの効果」カードつき（スライド28）。既存の `woundAndClot` の前半を詳しくした版
- `coagCascade`：外因性（組織因子＝第III因子）と内因性（第XII因子）から、活性化第X因子・第V因子・Ca²⁺・プロトロンビナーゼを経て、プロトロンビン（第II因子）→トロンビン、フィブリノゲン（第I因子）→フィブリン→活性化第XIII因子で安定化。舞台は血小板の膜の上（スライド29）
- `fibrinolysis`：プラスミンがフィブリンの網をほどく（スライド29）
- `megakaryocyteBudding`：巨核球の細胞質が分離帯で区画され、毛細血管にのびた突起の先から血小板がちぎれる（スライド27）
- `hematopoiesisTree`：多能性幹細胞 → 骨髄系幹細胞（CFU-E・CFU-Meg・CFU-GM）／リンパ系幹細胞 → 各成熟血球。マクロファージ、肥満細胞、形質細胞の枝も描く（スライド32）
- `stemCellSelfRenew`：幹細胞が自分を複製しながら前駆細胞を生む。CD34の目印、セルソーター、移植のアイコン（スライド30・33）
- `neutrophilMaturation`：骨髄芽球 → 前骨髄球 → 骨髄球 → 後骨髄球 → 杆状核球 → 分葉核球、「7〜14日」（スライド51）

**背景**
- 血管の裂け目の内側（コラーゲン線維が露出した壁）
- フィブリンの網の内側（赤血球がからまったところ）
- 骨の外から骨髄へ入るカット
- 骨髄の中：毛細血管（洞）、造血細胞の集まり、脂肪細胞。スライド27の図を参考に、模式的に描く
- 回想用のセピア調の骨髄

**キャラ**
- 新キャラのペタ（とその色違いの血小板隊）、キョウコ、造血幹細胞のシルエット（下の新キャラ欄）
- 幼いシロウ（回想）：今のシロウを scale 0.7 にし、胸章を「まっすぐな帯状の核（杆状核）」に替えた差分
- アカネ：`caught`（網にからまる）、`laugh`（ふき出す）

### 第4話
**模式図（新規）**
- `smearSteps`：スライドの上の血滴（約5 µL）、引きガラスの角度計（約30°）、押し進める方向の矢印、「0.5秒」のタイマー（スライド34・36）
- `smearQuality`：標本の4つの状態の切り替え。短く厚い、引き終わりがない、途中で止めた・縞、良好な標本（羽根状の引き終わり）。スライド43の表の該当行が光る演出つき（スライド43・44）
- `stainCharge`：塩基性色素（＋）が核・リボソーム・ヘパリンに、酸性色素（−）がヘモグロビン・好酸球の顆粒に結合し、それぞれの色に変わる図。メタクロマジーの注記と、ギムザ／ライトの○△表つき（スライド35）
- `smearZones`：標本全体の地図。引き終わりから1/5〜1/3が「適」、厚すぎ・薄すぎの部分は「不適」。視野が往復する矢印と、細胞が集まりやすい場所（スライド45）
- `sizeChart`：血球の大きさの比較（スライド47の値で描く）
- `granuleChart`：顆粒の大きさの比較（スライド48）
- `bandVsSegmented`：杆状核と分葉核の比較。「くびれが核の幅の1/3以下」の目安を示す（スライド65）
- `wbcDiffTable`：白血球分画の表。好塩基球 0〜1% が点滅する（スライド65）
- `peroxidaseChart`：ペルオキシダーゼ染色で陽性・陰性になる細胞の一覧（スライド57・58）

## 6. 資料の中で数値が食い違う箇所（作画・台詞のルール）
- **好中球の顆粒**：スライド15では特殊顆粒 0.2〜0.4 µm・アズール顆粒 0.5〜0.6 µm。スライド59では約0.2 µm と 0.4 µm。→ 台詞ではスライド15の値を使う。第4話の顆粒比較はスライド48の値（0.2〜0.4）で、両者は矛盾しない。
- **細胞の大きさ**：好酸球は 13〜17 µm（スライド18）、13〜18 µm（スライド47・48）、8〜14 µm（スライド60・65）。好塩基球は 12〜16 µm（スライド19・48）と 13〜18 µm（スライド61・65）。→ 台詞では好中球の約12 µm（第2話）とリンパ球の8〜9 µm（第2話）だけを言い、図はスライド47の値で描く。
- **白血球の割合**：第2話はスライド13・18・19・20・22の値（好中球60〜70%、好酸球2〜3%、好塩基球約0.5%、リンパ球25〜30%、単球約5%）。第4話の分画の表（スライド65）は臨床検査の基準の幅（好中球55〜77%、好塩基球0〜1% など）。→ 第4話の表には「白血球分画（資料の表）」と出典を添えて、数字が違っても混乱しないようにする。
- **好塩基球のペルオキシダーゼ染色**：スライド58では（＋）、スライド61では「陰性あるいは一部陽性」。→ 台詞では扱わない。
