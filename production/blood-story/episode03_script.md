# BLOOD STORY 第3話「ふさぐもの、生まれるところ」本編台本（草稿）

第2話のラスト（血管の裂け目にアカネが吸い寄せられる）から直結。前半は血小板と止血（粘着・放出・凝集 → 血液凝固）、
後半は「失われた血小板はどこから来るのか」をたどって骨髄へ向かい、巨核球と造血の系統を学ぶ。
内容は講義資料「血液」（スライド26–33・51・64）の範囲だけを使う。数値は資料の値（出典は末尾）。

話者：N＝ナレーション、A＝アカネ（赤血球）、ペタ（血小板・新キャラ）、キョウコ（巨核球・新キャラ）、ソウ（マクロファージ）
目安：約4分50秒〜5分（セリフ約1,380字＋無言の見せ場）。感情タグと読みは `episode_plan.md` の第3話の表を参照。

## 出典スライドと補足

- #3：血小板は正確には巨核球の細胞質の断片なので、ここでは「細胞」と言い切らず「仲間」と呼ぶ（#30で正体を明かす）。第1話#32の「核のない小さな破片」と矛盾しない。
- #5–9：直径 2〜4 µm の円盤状、15万〜40万（25万）/mm³、硝子部・顆粒部、核なし・周縁部に微小管、開放小管系（Ca²⁺を含み、Ca²⁺流入や顆粒内容放出の通路）、α顆粒（PDGF・凝固因子・フィブリノーゲン）、δ顆粒＝暗調小体（セロトニン：血管収縮、ADP：血小板凝集）、λ顆粒＝リソソーム（凝血塊の再吸収）（スライド26）。赤血球15〜20個に1個（スライド64）。暗調小管系（機能不明）は台詞では扱わない。
  ※微小管の束が「円盤の形を保つ」役割は資料にないので台詞にしない（補足）。
- #10–15：von Willebrand 因子を介したコラーゲンへの接着 → 開放小管系の Ca²⁺ で顆粒内容放出 → 血管収縮・凝集・偽足で傷口閉鎖・内皮等の増殖刺激・血液凝固の場（スライド28）。
- #16–17：血小板の応急の血栓にフィブリンがからみついて強固な血栓（スライド28）。
- #18–21、#25：血小板第3因子（膜リン脂質）上で凝固が進行、内因性（第XII因子）・外因性（組織因子＝第III因子）、プロトロンビン → トロンビン → フィブリノーゲン → フィブリン、重合して線維状、血餅／血栓、プラスミンによる線維素溶解系（スライド29の本文）。活性化第X因子・第V因子・Ca²⁺・プロトロンビナーゼ・活性化第XIII因子による安定化は、スライド29の図から。
- #22–24：赤血球が網にからまる＝「血球を巻き込んで血餅」（スライド29、スライド5）。アカネ本人がからまるのは演出（補足）。
- #28–31：巨核球は多分葉核、細胞質にα顆粒などができ、膜性の分離帯で区画、骨髄毛細血管内に伸びた細胞質突起の先端から分離して末梢血へ（スライド27）。
- #32–34：幹細胞（自己複製し前駆細胞を生む）、多能性・単能性幹細胞（スライド30）、造血の経路：多能性幹細胞 → 骨髄系幹細胞（CFU-E・CFU-Meg・CFU-GM）／リンパ系幹細胞（T・B・NK）（スライド32）、CD34（約110 kDa の膜蛋白質）、セルソーター、幹細胞移植、造血幹細胞はリンパ球に似た小さな細胞（スライド33）。
  ※CFU-GM から好酸球・好塩基球の系列まで含めて「顆粒球と単球」とまとめたのは、スライド32の図の枠組みに沿った簡略化（補足）。
- #35：骨髄芽球 → 前骨髄球 → 骨髄球 → 後骨髄球 → 杆状核球 → 分葉核球、骨髄で7〜14日（スライド51）。シロウの子ども時代は演出（補足）。
