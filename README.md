# MED·STUDY — 医学部向けインタラクティブ学習アプリ

講義資料（PDF）を一次資料にした、医学部生向けのインタラクティブ学習Webアプリです。
**授業を受ける → 図とアニメーションで仕組みを見る → 5択で確かめる → 間違いを復習する → 弱点を確認する** までを一つのアプリで完結できます。iPad（縦・横）を最優先に、PC・スマートフォンでも崩れないように作っています。

| 教材 | 内容 | 授業 |
|---|---|---|
| **遺伝医学｜遺伝子の基礎（構造と機能）**（既定） | 講義資料 2026.09.28（82枚、うち学習用62枚）→ 6章・5択124問・分子アニメ7本・図解7枚・図鑑20項目 | **黒板授業** 6コマ（各13〜16分、ニューラル音声収録済み） |
| 組織学｜細胞質 | 講義資料02（スライド2–56）→ 9章・5択110問＋正誤77問・アニメ6本 | 予備校スタイルの授業 9コマ |
| 組織学｜核・細胞周期 | 講義PDF「核、細胞周期」（24枚、うち学習用18枚）→ 6章・5択36問＋正誤18問・アニメ3本・図解5枚・図鑑11項目 | 予備校スタイルの授業 6コマ（各11〜13分、ニューラル音声収録済み） |

教材は 設定 → 教材 で切り替えます。

## 遺伝子の基礎：黒板授業

「スライドを読み上げるAI授業」ではなく、**先生が黒板にチョークで書きながら進める授業**です。

- **リアルな黒板**：画面いっぱいの黒板に、白・黄・赤・青のチョークで1文字ずつ書かれていく（文字は1〜3回の運筆で現れ、傾き・大きさ・筆圧が1文字ごとに違う）。線・矢印・丸囲み・下線もチョークが動いて描かれ、チョークの粉が落ち、消した跡がうっすら残る。先生の手（チョーク・黒板消し・指し示し）が見える
- **板書が授業の思考過程として積み上がる**：左＝基本概念、中央＝メカニズム、右＝試験ポイント、下＝まとめ。「DNA ↓ ？」→ ？を消してRNA → 転写・翻訳のラベル → 赤チョークで囲む、のように授業の流れがそのまま黒板に残る
- **カメラワーク**：書いている場所へ寄り、重要語に寄り、分子アニメへ切り替え、黒板全体へ戻る
- **黒板 → 分子アニメーション → 黒板**：二重らせん・DNAの収納・減数分裂と不分離・転写/スプライシング/翻訳・変異・エピジェネティック制御・レトロ転移
- **授業中の5択**：確認問題・典型問題（考える時間 → 正解 → 理由 → 他の選択肢が違う理由）・本番問題。解説では**黒板の該当箇所**を差し込み表示
- **授業の終わり**：完成した黒板を映し、「今日覚えてほしいのは…」で該当箇所を順に指して強調 → 今日の重要ポイント（3〜5個）→ 終了レポート
- **操作**：再生/一時停止/最初から/10秒戻る・進む/字幕/音量/速度（0.75〜2.0×）/**重要ポイントだけ**/**板書だけを見る**（完成した黒板・パン/ズーム・書き順で再生）/**5分復習**（完成した黒板 → 重要事項 → 重要図解 → 5問 → 間違えたポイント）
- **弱点分析**：テーマ別の理解度に加え、選んだ誤答から**「なぜ間違えたのか」**（用語の取り違え・向き/順序の逆転・数値・範囲の見落とし・機序の誤解・記載と異なる事実）を集計

内容はPDFに書かれていることだけを使い、資料外の知識は教科書・図で「補足」と明示しています。
到達目標にある「DNAの複製と修復」は、この講義資料では図中の矢印として示されるだけで詳しい内容がないため、収録していません（該当する資料を追加すると教材化できます）。

## 機能（両教材に共通の画面。数は組織学の例）

| 画面 | 内容 |
|---|---|
| ホーム | 今日の学習（次にやること3件）、理解度・正答率・学習時間・要復習数、細胞の見取り図（章へジャンプ）、最近学習したテーマ、復習が必要なテーマ、章一覧 |
| 教科書 | 章ごとの本文（明朝体の読み物）、出典スライド、赤シート（隠して確認）、たとえ・よくある勘違い・補足（授業資料外と明示）、インタラクティブ図、アニメーション、試験の急所、確認Q&A、読了管理 |

| 図解 | 構造をタップ → 医学名 → 工場での役割 → 実際の機能 → 出典スライド |
| アニメ | 6本の機序アニメーション（超遠心法・分泌・エンドサイトーシス・シグナル配列・モーター蛋白・線毛）。再生/一時停止/リスタート/速度/タイムライン/重要ポイントへジャンプ、チェックポイント、見終わった後の5択確認 |
| 図鑑 | 20の構造をたとえ付きカードで一覧 |
| 5択問題 | **全問A〜Eの5択**。110問（学習スライド55枚×2問）＋正誤5択77問＋アニメ確認問題18問。正解・各選択肢の解説・重要ポイント・出典（PDF スライド番号）・難易度・関連テーマ |

## 音声について

授業のナレーションは **ニューラル音声合成（Microsoft Nanami）で事前に収録した音声** を同梱しています（組織学 全9講・約139分、遺伝子の基礎 全6講・約88分、核・細胞周期 全6講・約69分）。再生中は音源が画面に表示されます。

1. **収録音声**（標準）：`public/courses/<id>/audio/lecture-NN.mp3` と `lecture-NN/manifest.json`。1講義＝1ファイルで、文ごとの位置を manifest に記録。台本のタイミングは実際の音声の長さで再計算されるので、字幕・ハイライト・アニメが声に同期します
2. **端末の音声合成**（収録音声が読み込めないとき）：Web Speech API
3. **音声なし**：字幕・台本・タイムスタンプで進行し、「音声なし（字幕で進行）」と表示

台本を変えたら `npm run build:narration` → `python3 scripts/generate-audio.py <course>` で録り直します（変更された文だけ再合成。[docs/AUDIO.md](docs/AUDIO.md)）。

授業は **予備校の講義スタイルの台本**（`src/content/courses/<id>/lessons/lecture-NN.md`）から作られます。遺伝子の基礎の台本は `@bb`（黒板）の指示で板書・カメラ・丸囲み・消去・指し示しまで記述します（[docs/LECTURE_SCRIPT.md](docs/LECTURE_SCRIPT.md)）。各講は「今日押さえてほしい3つ → 全体図と学習マップ → テーマごとに板書（結論→理由→仕組み）・スライドの根拠・比較表・混同注意／覚え方カード・アニメ → 確認問題と典型問題（考える時間 → 正解の根拠・問題文の見どころ・他の選択肢が違う理由・解き方）→ まとめ → 本番問題 → 終了レポート（理解度・正答率・間違えた問題・復習リンク）」の流れです。講師はオリジナルのキャラクターで、内容はPDFに書かれていることに限ります。書き方は [docs/LECTURE_SCRIPT.md](docs/LECTURE_SCRIPT.md)。

台本がない講義は `scripts/build-narration.ts` が教科書から講義口調に変換して自動生成します（だ・である → です・ます、視線誘導、自然な間、医学用語の読み補正）。

## 開発

```bash
npm install
npm run dev              # 開発サーバ
npm run build            # 型チェック + 本番ビルド（dist/）
npm run preview          # ビルドの確認（http://localhost:4173）

npm test                 # ユニットテスト（内容の整合性・読み変換・です/ます変換・進捗・分析・授業タイミング）
npm run test:e2e         # E2E（iPad横/縦・スマホ・PC の4画面サイズで全画面・問題・復習・授業・アニメを操作）
npm run check:content    # 教材データの検証（5択か、正解1つか、出典スライドがあるか…）
npm run build:narration  # 授業ナレーション（台本・字幕・タイミング・板書）を再生成（-- <course> [講番号]）
```

GitHub Pages などのサブパスに置く場合は `BASE_PATH=/medical-/ npm run build`。ルーティングはハッシュ方式なので、静的ホスティングだけで動きます。

## 構成

```
src/
  app/            ルーティング・レイアウト・コンテキスト
  components/     共通UI（スライド+赤シート、出典チップ、インタラクティブ図、タイムライン…）
  features/       画面（home, textbook, lecture, animations, figures, zukan, quiz, review, analytics, settings）
  engine/
    board/        黒板授業の板書データ型とcanvasレンダラ（チョーク・手・カメラ・消去）
    animation/    アニメーションの描画ステージ（React非依存・rAF駆動）
    lecture/      授業データ型とタイムライン計算
    speech/       読み変換（字幕→音声用テキスト）とナレーター（収録音声 / 端末音声）
  state/          学習履歴ストア（Repositoryで保存先を差し替え可能）と分析関数
  content/
    types.ts      教材データの型
    registry.ts   教材フォルダを自動登録（選んだ教材だけを読み込む）
    courses/genetics-basics/   遺伝子の基礎（黒板授業：lessons/lecture-01〜06.md）
    courses/histology-cytoplasm/
    courses/histology-nucleus/
      course.json  textbook.json  slides.json  zukan.json  map.svg
      questions/   single.json（5択） judgement.json（正誤5択）
      figures/     figures.json details.json
      animations/  meta.json scripts.json（台本） defs.ts（描画コード）
      narrations/  lecture-01.json … lecture-09.json（台本・字幕・タイミング）
public/courses/<id>/slides/  スライド画像
scripts/          教材の取り込み・新規教材の雛形・ナレーション生成・音声生成・検証
```

詳しくは [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)、教材の追加方法は [docs/ADDING_A_COURSE.md](docs/ADDING_A_COURSE.md)。
